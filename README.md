# MediaHub

MediaHub 是一个面向 Windows x64 的 C++20 / Qt 6.8 Widgets 桌面媒体播放器。它使用
libVLC 播放本地媒体和用户提供的直播地址，并集成了一个基于 Microsoft WebView2 的
独立网页模式。

当前源码版本为 `0.7.0`。v0.1 至 v0.7 均已按本地自用版本完成；v0.7 在保留网页页
现有结构的前提下，完成本地/直播界面、个性化主题、辅助窗口和响应式布局重构。

## 项目定位

MediaHub 将本地播放器、直播播放和网页浏览放在同一个桌面程序中，但三条能力链路
保持边界清晰：

1. 本地媒体通过 libVLC 播放，支持音频、视频、播放列表、歌词、进度、音量和全屏。
2. 直播通过用户输入的 URL 或 M3U/M3U8 清单接入，不内置频道库，不抓取第三方频道。
3. 网页由独立的 WebView2 后端负责，不把网页地址提取后交给 libVLC，也不与系统 Edge
   共享个人 Profile。

核心逻辑可以在不安装 Qt、libVLC 和 WebView2 的情况下单独构建和测试。界面支持库
只依赖抽象接口，不直接链接 libVLC；具体播放内核和 WebView2 适配器由程序入口组装。

## 版本演进

项目按版本顺序逐步扩展，每个版本都有对应的规划、测试和交付记录。

### v0.1：本地音视频播放

v0.1 建立了播放器的基础能力和核心架构：

- 从文件菜单、资源管理器拖放或命令行参数打开本地媒体。
- 播放、暂停、继续、停止、进度显示、拖动定位和音量控制。
- 视频画面输出、纯音频波形、全屏和安全关闭。
- 播放列表、双击播放、拖放添加、多选操作、上一首和下一首。
- 顺序、列表循环、单曲循环和随机播放。
- 中文路径、空格路径、失败提示和错误恢复。
- 纯音频内嵌歌词和在线歌词查询。

v0.1 只定义本地媒体播放，不把网络音频或直播地址作为第一版能力承诺。阶段 0 至
阶段 12 的本地播放器实现已经封存。

### v0.2：URL 直播和远程清单

v0.2 增加用户提供的网络直播能力，并保持本地媒体与直播列表分开：

- 支持 `http`、`https`、`rtsp`、`rtmp`、`rtmps`、`udp`、`rtp` 和 `srt` 等地址。
- 连接期间显示缓冲状态，15 秒未开始播放时报告连接超时。
- 停止、切换和关闭可以取消或隔离正在连接的旧播放器，迟到事件不会覆盖新媒体。
- 网络媒体始终按直播处理，未知总时长和不可定位状态不会错误启用进度拖动。
- “刷新直播”按钮和 `F5` 可重新打开当前直播，不新增列表项或重复最近地址。
- 读取远程 M3U/M3U8 文本并显示扁平直播列表，不下载清单中的音视频文件。
- 清单读取限制为 10 秒、5 次安全重定向、2 MiB 正文和 5000 个条目。
- 清单失败时保留上一次有效列表；普通 HLS 分片清单不会被错误识别为频道列表。
- 直播条目支持播放、停止、会话内标记不可用和收藏，不提供频道分类、排序或删除。

v0.2 已完成 Debug/Release 回归、Core-only 回归、发布包验证和用户真实清单验收。

### v0.3：三种播放场景界面

v0.3 在不改变播放命令语义的前提下重构界面：

- 本地音频使用明亮、低饱和绿色的音乐界面和波形/歌词区域。
- 本地视频使用低干扰的深色影院画布，视频帧仍由 libVLC 输出。
- 直播使用紧凑工具区，集中显示清单地址、载入、定位和连接状态。
- 三种模式复用相同的播放列表、快捷键、控件和 Presenter 路由。
- 小窗口、全屏和 100%/125%/150% 模拟缩放纳入 GUI 回归。

### v0.4：状态恢复和快捷键

v0.4 增加了本地使用所需的恢复与辅助能力：

- 保存和恢复本地播放列表的顺序及列表内显示名，但启动不会自动播放。
- 保存最后使用的直播清单 URL 和有限的会话内清单历史。
- 增加直播源资料窗口，可保存地址和备注，编辑行为不改变播放链路。
- `F11` 双向切换全屏，`Ctrl+上键`/`Ctrl+下键`恢复或静音。
- 增加快捷键帮助窗口，编辑文本时不会误触发播放器方向键快捷键。

### v0.5：直播和本地媒体日常增强

v0.5 继续完善本地媒体与直播清单的日常使用：

- 直播列表支持中文和不区分大小写的即时搜索。
- 直播源可以收藏、标记为会话内不可用，并提供“定位正在播放”。
- 本地媒体支持最近播放和安全断点续播；启动只恢复展示，不自动播放、定位或联网。
- 直播切换和慢连接取消不会阻塞 GUI，也不会让旧直播抢回音频或视频输出。
- 本地视频列表最后一项自然结束后，点击播放可以重新创建画面并继续播放。
- 直播切换、M3U/M3U8 解析、路径、错误恢复、图标和退出过程均补充了回归验证。

### v0.6：内置网页浏览器

v0.6 增加与“本地”“直播”并列的“网页”模式。最终版本在浏览器基线之上完成了多
标签、资料持久化、后台运行、下载中心、性能优化和界面重构。

- 使用固定版本 WebView2 SDK 和 MediaHub 专用 Profile，不读取或修改系统 Edge Profile。
- 支持地址栏、后退、前进、刷新、主页、网页内查找和网页全屏。
- 支持多标签切换、拖动、关闭、恢复、固定、分组、搜索和每标签缩放。
- `window.open`、`target=_blank` 和登录弹窗请求转为共享 Profile 的新标签。
- Bing 作为首次就绪和主动新标签的默认主页；清除网页资料后回到内部空白页。
- 历史和收藏支持有界持久化、标题/备注编辑、搜索和收藏 HTML 导入导出。
- 历史、收藏、声音、标签搜索、分组、下载和网站权限使用统一右侧侧栏。
- 多任务下载中心支持进度合并、完成、失败、取消、可恢复中断和退出确认。
- 切换到本地或直播时只隐藏网页，不主动挂起、静音、销毁或重新导航 Controller；
  后台网页和下载继续运行。切换到网页也只改变页面可见性，不暂停活动的原生媒体，
  直播和本地媒体都可在后台继续播放。
- 权限、屏幕捕获、下载、上传、外部协议和证书错误均经过显式安全决策。
- 网页标签、历史、收藏、会话和下载的高频更新使用缓存、脏标记或延迟合并，减少 GUI
  主线程上的重复读取、列表重建、DPAPI 检查点和进度刷新。
- 移除网页宿主不必要的原生窗口层级，修复持续拖动时网页落后和黑屏问题；最终用户
  验收确认窗口跟手、网页不黑屏、侧栏关闭后内容恢复全宽。

v0.6 按本地自用版本完成。原 W-M01 至 W-M18 中未逐项补证的真实账号、DRM、外部协议、
自签名证书、公共网站和跨机器场景继续作为公开发布与兼容性边界，不改写为通过。

### v0.7：本地与直播界面及主题重构

v0.7 将本地和直播页统一为更紧凑的成熟桌面播放器结构，网页页内部 UI 保持不变。

- 顶部文件、视图、帮助和主题入口改为统一图形按钮，集中放在右上角。
- 本地和直播页使用连续媒体舞台、响应式队列和底部播放坞，浅色模式同步覆盖列表、
  倍速、跳转和播放模式悬浮面板。
- 音频波形恢复为从底部向上的单向真实 PCM 曲线，波形与歌词共享同尺寸背景区域。
- 支持深色/浅色模式、五套完整预设、自定义 RGB、本机背景图片、模糊度和背景清晰度。
- 主题滑杆支持轨道绝对定位；拖动期间只更新滑杆和数字，松手后一次性刷新整窗主题。
- 快捷键与直播源备忘窗口改为平面桌面工具窗口，保留原有保存、校验和关闭行为。
- 在本地或直播页调整窗口后切回网页，会先同步 WebView2 边界再恢复显示，避免黑区。

用户已完成最终实机确认；Release 全量 CTest `92/92` 通过，正式包位于
`dist/MediaHub-0.7.0-win64/`。

## 功能总览

### 本地媒体

#### 输入

- 文件菜单选择一个或多个本地文件。
- 从资源管理器拖放文件到主窗口。
- 启动时传入多个本地媒体路径，输入顺序会保留。
- 文件选择器提供常见音频、视频和播放列表扩展名；最终格式能力由 libVLC 及其插件决定。

程序支持中文路径和空格路径。选择“所有文件”后打开不受支持或损坏的文件时，会显示
可读的中文错误，而不是崩溃或自动跳到下一项。

#### 播放列表

- 本地播放列表保存媒体源路径、顺序和列表内显示名。
- 同一路径重复添加按追加处理，不默认去重。
- 双击项目立即切换并播放；右键菜单支持播放、暂停、停止、置顶、上移、下移、重命名
  显示名和移出列表。
- 重命名只改变列表显示名，不修改磁盘上的文件名。
- `Ctrl` 支持不连续多选，`Shift` 支持连续多选；多选时只有移出列表可用。
- 播放列表旁的箭头可以折叠和展开列表，媒体区域会随剩余空间调整。

#### 播放控制

- 控制行包含进度、上一首、播放/暂停、下一首、停止、音量、歌词、倍速、跳转步长、
  播放模式和全屏。
- 已知时长且可定位的媒体支持轨道单击和拖动定位；拖动期间保留用户预览，松手只提交
  一次定位请求。
- 音量范围为 0 至 100；音量按钮可静音和恢复，恢复时保留此前音量。
- 支持 0.5x、0.75x、1.0x、1.5x、2.0x、3.0x 六档播放速度。
- 左右键跳转步长支持 5、10、15、20 秒，默认 5 秒。
- 音频和视频都支持进入、退出全屏；音频全屏显示波形或歌词，视频全屏显示原生画面。
- 媒体自然结束、失败、停止和切换均有明确状态，失败项可以重新选择恢复。

#### 音频波形和歌词

- 纯音频显示固定底部波形，使用运行时 PCM 强度驱动，波形不随进度横向移动。
- 波形使用固定 192 个绘制点并缓存静态背景，避免全屏时计算量随宽度增长。
- “词”按钮在波形和歌词之间切换。
- 优先读取音频内嵌歌词，再按酷狗、网易云、LRCLIB、TheAudioDB 顺序查询。
- 同步歌词随播放位置高亮，普通歌词显示全文滚动内容。
- 歌词查询异步执行并缓存；断网、超时或无结果不影响媒体播放。
- `+0.5s` 和 `-0.5s` 可以按歌曲保存时间轴校准值，不记录本地完整路径。

### 直播和清单

打开“文件 → 打开网络地址”后，可以输入用户自行选择的直播 URL。网络直播与本地播放
列表分开显示，不会把网络地址当成本地文件处理。

支持的常见协议包括：

```text
http  https  rtsp  rtmp  rtmps  udp  rtp  srt
```

直播使用异步连接和专用控制线程。连接中可以停止或切换，15 秒未开始播放会报告超时；
用户可以点击“刷新直播”或按 `F5` 重新打开当前地址。直播没有可靠的统一总时长，因此
主进度条通常显示不可定位状态。

远程清单支持 M3U/M3U8 文本读取：

- 只读取清单文本，不下载清单中的媒体内容。
- 限制正文大小、条目数、重定向次数和读取时长。
- 清单中的条目保持顺序，显示为扁平直播列表。
- 新清单失败时保留上一次成功列表。
- `.m3u` 始终按频道清单处理；`.m3u8` 识别到真实 HLS 控制标签后才回退为直接播放。
- 直播条目可以播放、停止、收藏或标记不可用，但不提供文件式重命名和删除。

软件不内置频道库、不搜索或托管第三方频道，Logo、EPG、频道分类和定时订阅不在当前
范围内。

### 内置网页浏览器

网页页是独立展示模式，不会把网页媒体地址交给 libVLC。

#### 浏览器栏和标签

- 两层顶部 Chrome 包含标签栏、地址栏、导航按钮、主页、收藏入口和更多操作。
- 每个标签单独保存地址、标题、导航代次、前进/后退状态、静音状态和缩放状态。
- 支持新建、切换、拖动、关闭、复制、固定、分组、搜索和恢复关闭标签。
- 最后一个标签关闭时复用存活 Controller，不留下没有后端的空标签。
- 浏览器会话在退出和启动时恢复标签、固定状态、分组和当前标签。
- 标签、历史、收藏、下载、声音、权限和分组使用同一个右侧侧栏，不再打开多个独立
  辅助窗口。

#### 导航、资料和安全决策

- 空地址不导航；普通域名自动补为 HTTPS。
- `javascript:`、`data:` 顶层地址和不允许的内部页会被拒绝。
- `file:`、外部协议、自签名证书、设备权限、屏幕捕获、下载和上传按当前安全策略处理。
- 权限对话框区分允许一次、对本站记住、拒绝和取消；保存的权限按来源隔离。
- “清除网页数据”只清除 MediaHub 浏览器 Profile 的 Cookie、站点存储、缓存、保存的
  密码、自动填充和当前会话证书例外，不影响系统 Edge。
- 浏览历史和收藏保存经过规范化的宿主元数据，不写入密码、Cookie、Token 或完整查询。

#### 后台运行和下载

- 切换到本地或直播时，网页 Controller 保持后台运行，只改变可见性。
- 后台网页不因界面切换被自动挂起、静音、销毁或重新导航。
- 页面切换不会暂停或自动恢复原生媒体；只有用户明确点击播放/暂停、停止、刷新、切台
  或关闭程序时才改变原生播放会话。
- 下载中心集中显示并发下载，频繁字节进度按约 150 毫秒合并，完成、失败、取消和可
  恢复中断立即更新。
- 应用退出时如果存在活动下载，会先显示确认；确认退出才取消并关闭相关任务。

## 使用方式

### 启动程序

使用已经构建的 Debug 程序：

```powershell
.\cmake-build-debug\MediaHub.exe
```

直接打开本地媒体并按输入顺序加入列表：

```powershell
.\cmake-build-debug\MediaHub.exe "C:\Media\one.mp4" "C:\Media\two.mp3"
```

正式发布目录的启动程序为：

```powershell
.\dist\MediaHub-0.7.0-win64\MediaHub.exe
```

运行网页模式需要目标机器预先安装 WebView2 Evergreen Runtime。发布目录必须整体保留，
不能只复制 `MediaHub.exe`。

### 基本操作顺序

1. 启动程序后，在“本地”“直播”或“网页”三个入口中选择工作模式。
2. 本地模式使用“打开文件”、拖放或命令行参数加入媒体。
3. 直播模式使用“打开网络地址”输入流地址，或在直播页载入 M3U/M3U8 清单。
4. 网页模式在地址栏输入地址，或使用主页、历史、收藏和新标签打开页面。
5. 播放列表中双击项目切换播放，主控制行负责暂停、定位、音量、倍速和全屏。
6. 关闭窗口前等待正在写入的状态或下载完成；活动下载会获得明确的退出确认。

### 快捷键

| 快捷键 | 作用 | 适用范围 |
|---|---|---|
| `Space` | 播放或暂停 | 播放器 |
| `Up` / `Down` | 每次调整音量 5% | 播放器 |
| `Left` / `Right` | 按当前步长后退或快进 | 可定位媒体 |
| `Ctrl+Left` / `Ctrl+Right` | 切换上一首或下一首 | 播放列表 |
| `F11` | 进入或退出应用全屏 | 主窗口 |
| `Ctrl+Up` / `Ctrl+Down` | 恢复声音或静音 | 播放器 |
| `F5` | 刷新当前直播；网页中刷新页面 | 直播/网页 |
| `Ctrl+L` | 聚焦地址输入 | 直播或网页 |
| `Alt+Left` / `Alt+Right` | 后退或前进 | 网页 |
| `Ctrl+R` | 刷新网页 | 网页 |
| `Ctrl+T` | 新建网页标签 | 网页 |
| `Ctrl+W` | 关闭当前网页标签 | 网页 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换下一个或上一个标签 | 网页 |
| `Ctrl+Shift+T` | 恢复最近关闭的标签 | 网页 |
| `Ctrl+F` | 查找当前网页内容 | 网页 |
| `Esc` | 优先退出网页全屏或关闭网页查找 | 网页 |

网页输入框、网页正文和查找框获得焦点时，文本编辑和网页快捷键优先于播放器快捷键。

## 生成发布包

发布包需要使用独立的 Release 构建目录和此前不存在的安装前缀。目标机器需要安装
Microsoft Visual C++ 2015-2022 Redistributable（x64）和 WebView2 Evergreen Runtime
（x64）。WebView2 Loader 静态链接，正式包不应出现 `WebView2Loader.dll`。

```powershell
cmake -S . -B cmake-build-release -G Ninja `
      -DCMAKE_BUILD_TYPE=Release `
      -DCMAKE_PREFIX_PATH="C:/Qt6.8/6.8.3/msvc2022_64" `
      -DMEDIAHUB_VLC_ROOT="C:/SDK/vlc-3.0.21" `
      -DMEDIAHUB_WEBVIEW2_ROOT="Third_Party/webview2" `
      -DMEDIAHUB_QT_LICENSE_DIR="<含 LICENSE.LGPLv3 和 LICENSE.GPLv3 的 Qt 目录>" `
      -DMEDIAHUB_PACKAGE_RELEASE=ON

cmake --build cmake-build-release
ctest --test-dir cmake-build-release --output-on-failure
cmake --install cmake-build-release --config Release `
      --prefix dist/MediaHub-0.7.0-win64
cmake "-DMEDIAHUB_PACKAGE_DIR=dist/MediaHub-0.7.0-win64" `
      -P tools/validate_release_package.cmake
```

发布包校验器会检查：

- 顶层 `MediaHub.exe`、Qt 运行库、libVLC 两个 DLL 和完整的 365 个 VLC 插件。
- 六项法律材料，包括 Qt、VLC 和 WebView2 的许可证/NOTICE 文件。
- 不存在 WebView2 Profile、Cache、Cookie、构建目录、测试程序、调试文件或错误架构。
- 不存在符号链接、junction、reparse point 和动态 `WebView2Loader.dll`。

当前 Qt6 候选目录为 `dist/MediaHub-0.7.0-win64-qt6-candidate/`：398 个文件，总大小
213,601,651 字节（203.71 MiB）；`MediaHub.exe` 大小为 3,041,792 字节，SHA-256 为：

```text
6EFB302D42E41E7DB3C7BF36E150C860C5DE3EF6AC0E18F898012137726252A8
```

发布目录由 Git 忽略，不进入源码提交。Qt、VLC、插件、图标和法律材料必须与 EXE 一起
保留，不能只复制 `MediaHub.exe`。

## 架构与目录

### 依赖方向

```text
mediahub_gui
  ├── mediahub_browser_webview2 ──> mediahub_gui_support ──> mediahub_core
  │             └── WebView2 SDK / Windows COM
  └── mediahub_engine_vlc ───────> mediahub_core
                └── libVLC
```

三条硬性边界：

1. `mediahub_core` 不依赖 Qt、libVLC、WebView2 或 Windows 类型。
2. `mediahub_gui_support` 不包含 WebView2/COM 头文件，不链接 WebView2 SDK，也不链接
   libVLC。
3. 内核事件回调不操作 Qt 控件，不调用等待内核线程的接口；事件必须投递到 GUI 主线程。

只有 `apps/gui/main.cpp` 负责把具体播放内核、浏览器后端和界面支持库组装起来。

### 主要目录

```text
MediaHub/
├── apps/gui/                         Qt 主窗口、Presenter、浏览器页面和视图模型
├── include/mediahub/core/            不依赖 Qt/libVLC 的核心接口和值类型
├── include/mediahub/engine_vlc/      libVLC 内核公共接口
├── include/mediahub/browser_webview2/ WebView2 后端公共 PImpl 接口
├── src/core/                         播放状态、播放列表、M3U 等纯核心实现
├── src/engine_vlc/                    libVLC 内核实现
├── src/browser_webview2/              WebView2、COM 和 Controller 实现
├── src/logging/                       结构化终端日志实现
├── tests/unit/                        核心单元测试
├── tests/integration/                 libVLC/WebView2 集成测试
├── tests/gui/                         Qt GUI 测试和浏览器行为测试
├── Third_Party/googletest/            GoogleTest 1.17.0
├── Third_Party/webview2/              WebView2 SDK 1.0.4129.50
└── tools/                             探针、发布包校验器和隔离运行脚本
```

第三方源码保持上游原貌，libVLC 作为外部 SDK 通过 `MEDIAHUB_VLC_ROOT` 接入，不进入
`Third_Party/` 或 Git 仓库。

## 安全与隐私

### 本地媒体和直播

- 播放链路只读取用户选择的媒体文件，不修改、移动、删除或重命名原文件。
- 直播地址由用户提供，程序不内置频道库，不搜索、抓取或托管第三方频道。
- 完整直播 URL 只在当前进程内使用；日志、错误和列表名称不记录凭据、查询参数或片段。
- 测试媒体在运行时生成，不提交有版权的音频或视频素材。

### 歌词网络请求

- 歌词查询只发送标题、艺术家、专辑和时长，不上传音频内容和本地文件路径。
- 查询结果写入应用缓存目录，不修改媒体文件。
- 酷狗和网易云接口属于非官方接口，当前仅按个人本地使用范围接入。

### 浏览器 Profile

- MediaHub 使用独立 WebView2 Profile，不读取、写入或删除系统 Edge 个人资料。
- Cookie、密码、Token、LocalStorage、IndexedDB 和缓存由 WebView2 Profile 管理，不进入
  MediaHub 的播放器状态、`QSettings`、测试证据或生产日志。
- 权限、外部协议、证书、下载、上传和屏幕捕获需要明确的安全决策。
- 测试和日志不记录真实账号、完整网页地址、查询参数、下载路径、Profile 路径或私人截图。

### 发布合规

- 发布包包含依赖许可证和 NOTICE 材料，但项目自身源码许可证尚未决定。
- 对外分发前还需要完成许可证合规确认，并在无开发环境的 Windows x64 机器或虚拟机
  复测完整发布目录。

## 交付状态与限制

v0.7 的定义是“本地自用版本完成”，不是面向公众的正式发行声明。以下事项仍是已知限制：

- 仅支持 Windows x64。
- 网页能否播放特定视频、直播或 DRM 内容取决于 WebView2 Runtime、系统编解码器、网站
  策略、账号状态和地区限制，项目不绕过这些限制。
- 原 W-M01 至 W-M18 中未逐项补证的真实账号、真实权限设备、外部应用、自签名 HTTPS、

- 具体音视频格式能力由 libVLC 和随包插件决定，项目不为每一种格式单独承诺。
- 音画输出、音画同步、真实网站兼容性和声音效果不能只由自动化测试判断。
- 当前源码已迁移到 Qt 6.8.3；Qt 5.14.2 只在历史阶段文档中保留，不再是构建或发布依赖。
- 发布包体积较大，主要来自 libVLC 插件目录。
