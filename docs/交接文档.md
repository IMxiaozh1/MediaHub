## 1. 使用说明

本文件用于在不同开发窗口之间传递当前状态。开始新会话时先阅读本文件和项目根
目录的 `AGENTS.md`，然后执行：

```powershell
git status --short --branch
```

实际 Git 状态优先于本文档。如果两者不一致，先查明原因并更新本文档，不要直接
开始下一阶段。

每个阶段实现完成、规定测试通过且阶段测试文档回填后，自动创建本地 Git 提交；
测试失败或存在阻塞项时不提交。远程认证可用且没有冲突时自动推送，然后继续下一
阶段；禁止覆盖远端历史。

## 3. 长期开发规则

- 使用 C++20、CMake、Ninja、Qt 5.14.2 和 GoogleTest。
- 公共核心头文件放入 `include/mediahub/core/`，实现放入 `src/core/`。
- 内核实现放入 `src/engine_vlc/`，公共头文件放入 `include/mediahub/engine_vlc/`。
- GUI 代码放入 `apps/gui/`。
- 测试分别放入 `tests/unit/`、`tests/integration/` 和 `tests/gui/`。
- 每个阶段编写独立的 `docs/测试/阶段N测试.md`。
- 第三方源码统一放入 `Third_Party/<library>/`，不直接修改。
- **libVLC 不进入仓库**，通过 `MEDIAHUB_VLC_ROOT` 指向本机目录。
- **核心层不得依赖 Qt 和 libVLC。**
- **GUI 层不得链接 libVLC。**
- **内核事件回调中不得操作 Qt 控件。**
- `main.cpp` 只处理程序边界、对象组装和异常兜底。
- 项目自有代码注释必须使用中文。
- 涉及线程的函数，注释必须写明调用线程。
- 测试媒体在运行时生成，不依赖固定盘符或个人路径。
- 不提交任何有版权的音视频素材。
- 不提交 `build/`、`cmake-build-*/`、`.idea/` 和 `.vs/`。

## 6. 已完成增量：在线歌词

**目标**：为纯音频增加圆形“词”按钮与在线歌词显示，不改变本地媒体播放链路。

**具体工作**：

1. 歌词按钮放在音量按钮旁边，保持圆形控制样式，按钮文字为“词”。
2. 优先读取音频内嵌歌词；在线查询按酷狗、网易云、LRCLIB、TheAudioDB 的顺序降级。
3. 酷狗按歌曲分组和音频条目哈希优先提供精确时间轴；网易云补中文同步与翻译歌词；
   LRCLIB 补同步歌词；TheAudioDB 补海外普通歌词、封面、专辑与艺术家信息。
4. 使用标题、艺术家、专辑和时长共同匹配，避免同名歌曲误配；查询异步执行并缓存，
   断网、超时或无结果时不影响播放。
5. 已完成按钮、歌词显示、录音变体排除、单曲时间校准，以及同步歌词、普通歌词、
   顶部信息和校准控件的全屏响应式缩放；封面与艺术家展示保留为后续增量。

**通过条件**：按钮布局稳定，歌词可切换显示，同步歌词跟随进度，失败可安全降级，
播放、倍速、波形和全屏行为无回归。

**结果**：两首真实 MP3、全屏进入/退出和响应式字号实机验收通过，Release 全量
CTest `44/44` 通过。阶段 12 从 Release 隔离目录、许可证材料和最终交付清单开始。
