## 3. 依赖和部署变化

- CMake 使用 `find_package(Qt6 6.8 ...)` 和 `Qt6::` targets。
- `windeployqt` 从 `Qt6::qmake` 同一 SDK 的 `bin` 目录定位。
- 发布校验器允许 Qt6 Release TLS/网络插件，精确拒绝 Qt6 Debug 模块和 Qt5 DLL。
- Qt6 播放状态写入独立 `MediaHubQt6` 配置；首次启动从旧 `MediaHub` 配置完整导入，已有
  Qt6 直播源备注优先，旧版独有地址按 URL 追加一次。
- Qt 许可证材料更新为 Qt 6.8.3 对应材料；libVLC、WebView2 和 GoogleTest 不变。
- 目标机器仍需 MSVC 2022 x64 Redistributable 和 WebView2 Evergreen Runtime。
