# MediaHub 0.4.0 版本完成说明

> 本地自用完成日期：2026-08-07。
>
> 状态：状态持久化、快捷键、辅助窗口、自动化回归和 Windows 人工验收均已完成；
> 本版本没有单独生成 Release ZIP，也未作为公开发行版发布。
>
> 分类：交付。

## 1. 完成结论

MediaHub 0.4.0 在不改变 v0.3 播放与界面契约的前提下，完成本地播放列表、最后直播
清单 URL 和成功清单历史的本机持久化，补齐历史直播源、直播源资料、快捷键帮助和
载入取消入口。启动恢复只更新界面，不自动打开媒体、解析清单、播放或访问网络。

规划中的 P-01 至 P-17 已由自动化或人工验收覆盖。用户确认跨重启恢复、全屏、静音、
直播源资料和窗口交互均正常；2026-08-10 的可读性与方向键修正也已归档到 v0.4
边界，版本按本地自用标准完成。

## 2. 已完成能力

- 保存本地列表顺序、源路径和列表内显示名；新增、移出、排序和重命名后同步更新。
- 保存最后直播清单 URL，以及最近优先、去重、最多 20 项的成功清单历史。
- 历史按钮打开独立窗口，支持回填、删除和取消；回填不会自动载入清单。
- 清单载入期间按钮可取消，取消后隔离迟到结果并保留上一次有效直播列表。
- `F11` 双向切换全屏，`Ctrl+下键` 静音，`Ctrl+上键` 恢复；单独 `F5` 继续刷新
  当前直播，`Ctrl+F5` 不分配功能。
- “帮助 -> 快捷键”显示当前实际支持的快捷键；“帮助 -> 直播源”和主窗口 `Ctrl+M`
  打开独立资料窗口。
- 直播源资料支持地址、备注、新增、删除、保存、`Ctrl+S`、返回和关闭前确认；资料
  只保存到本机，不解析、不播放。
- 历史直播源和直播源资料窗口移除无功能的标题栏“？”，长备注默认换行并按内容增高。
- 资料单元格编辑时左右方向键只移动文本光标，不再被主窗口的定位或临时倍速快捷键
  拦截。

## 3. 数据、安全与架构边界

- 状态通过 GUI 支持层的可注入存储边界写入用户级 `QSettings`；测试使用临时 INI，
  不读取或污染真实配置。
- 本地完整路径、直播清单 URL、直播源地址和备注不写入日志或仓库。
- 启动恢复、历史回填和直播源资料编辑都不会调用播放内核、清单服务或歌词服务。
- 删除历史和资料只删除 MediaHub 配置记录，不修改用户媒体文件或远端内容。
- `mediahub_core` 继续不依赖 Qt/libVLC，`mediahub_gui_support` 继续不链接 libVLC。

## 6. 交付边界与已知限制

- 本版本按本地自用标准完成，没有独立发布目录、ZIP 或哈希，也没有第二台无开发环境
  Windows 的验证证据。
- 状态只保存在当前 Windows 用户配置中，不提供云同步、导入导出、加密存储或多用户
  合并。
- 保存的直播源资料只是用户备忘，不验证地址可用性，不替代直播列表，也不内置或搜索
  任何直播源。
- v0.4 不包含直播搜索、收藏持久化、最近播放或断点续播；这些能力从 v0.5 开始提供。
