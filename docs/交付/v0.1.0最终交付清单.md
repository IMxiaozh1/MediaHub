## 3. 功能与安全边界

本版本提供：

- Windows x64 本地 MP3、MP4、WAV 等 libVLC 可解码媒体的播放。
- 播放、暂停、停止、定位、音量、静音、倍速、上一首和下一首。
- 顺序、列表循环、单曲循环和随机播放。
- 播放列表折叠、多选、右键排序、列表内重命名和移出列表。
- 视频与纯音频波形全屏，以及随区域响应式缩放的在线同步歌词。
- 内嵌歌词、酷狗、网易云、LRCLIB 和 TheAudioDB 逐级歌词查询与单曲时间校准。

安全边界：

- 不修改、移动、删除或重命名用户磁盘中的媒体文件。
- 列表内“删除”和“重命名”只改变播放列表状态，不操作源文件。
- 不接受网络媒体地址或直播流；联网只用于歌词与音频元数据。
- 歌词查询不上传音频内容或本地完整路径。
- 不提交测试媒体、歌词正文、缓存、用户配置或本地发布二进制。

## 6. 快速验收

在 VS 2022 x64 开发者终端构建发布候选：

```powershell
cmake -S . -B cmake-build-stage12-release -G Ninja ^
      -DCMAKE_BUILD_TYPE=Release ^
      -DCMAKE_PREFIX_PATH="C:/Qt/Qt5.14.2/5.14.2/msvc2017_64" ^
      -DMEDIAHUB_VLC_ROOT="C:/SDK/vlc-3.0.21" ^
      -DMEDIAHUB_PACKAGE_RELEASE=ON
cmake --build cmake-build-stage12-release
ctest --test-dir cmake-build-stage12-release -C Release --output-on-failure
cmake --install cmake-build-stage12-release --config Release ^
      --prefix dist/MediaHub-0.1.0-win64
cmake -DMEDIAHUB_PACKAGE_DIR=dist/MediaHub-0.1.0-win64 ^
      -P tools/validate_release_package.cmake
```

隔离播放并检查依赖来源与正常退出：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass ^
  -File tools/stage12_isolated_smoke.ps1 ^
  -PackageDirectory dist/MediaHub-0.1.0-win64 ^
  -MediaPath "C:/path/to/owned-test-media.mp3"
```

## 7. 已知限制

- 仅正式支持 Windows x64。
- 不支持网络媒体地址和直播流；在线能力只用于歌词与元数据。
- 不支持字幕、多音轨、截图、录制、媒体库、历史记录或收藏。
- 格式与编解码能力取决于 libVLC 和发布包中的插件，不承诺所有格式。
- 视频画面、声音输出和音画同步依赖人工验收，自动化不能覆盖真实感官质量。
- 只完成人工 MP3/MP4 主路径，FLAC、MKV、大文件和长列表集中观察仍不完整。
- Windows 系统级 125%/150% 显示缩放尚未复测；强制 Qt 缩放已经通过。
- 没有第二台无开发环境 Windows 或虚拟机，当前为同机最小环境隔离验证。
- Qt 5.14.2 已归档，本机缺少它所需的 OpenSSL 1.1 运行库；歌词备用 HTTPS 源可能
  跳过，酷狗和网易云 HTTP 降级仍可用。
- 酷狗和网易云为非官方接口，TheAudioDB 免费条款限制公开应用分发，正式发布前需
  重新评估稳定性、平台条款与歌词版权。
- VLC 完整插件目录约占主要包体积，GPL 插件未逐项裁剪。
- MediaHub 自身源码许可证尚未决定。
