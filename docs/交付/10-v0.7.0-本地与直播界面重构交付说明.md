# MediaHub 0.7.0 本地与直播界面重构交付说明

> 交付日期：2026-08-20
>
> 状态：本地自用版本完成，长直播切换与帮助窗口深色适配修复已纳入正式包

## 1. 交付范围

MediaHub 0.7.0 在不改变播放内核、线程边界、直播清单和网页浏览器行为的前提下，完成
本地与直播页的成熟桌面播放器风格重构，并增加可持久化的个性化主题。

- 本地和直播页统一为连续媒体舞台、响应式右侧列表和底部播放坞。
- 文件、视图、帮助和主题使用右上角统一图形按钮；网页页内部 Chrome 保持 v0.6 结构。
- 支持深色/浅色模式、五套完整配色、自定义 RGB、本机背景图片、模糊度和背景清晰度。
- 波形与歌词共用同尺寸背景；音频波形只从底部向上生长，不使用上下镜像。
- 播放列表字体按窗口四档缩放，横向滚动条、浅色列表和悬浮面板完整适配主题。
- 快捷键和直播源备忘窗口改为平面工具窗口，保留原有保存、校验和关闭语义。
- 快捷键和直播源备忘的表头、行、空白区、编辑器及 Windows 标题栏完整跟随深浅主题。
- 主题滑杆点击轨道直接到达目标值，拖动期间不刷新整窗样式，松手后只提交一次预览。
- 跨页调整窗口后切回网页，会先同步 WebView2 边界再恢复显示，避免旧尺寸黑区。
