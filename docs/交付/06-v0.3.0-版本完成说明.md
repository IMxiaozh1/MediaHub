# MediaHub 0.3.0 版本完成说明

> 本地自用完成日期：2026-08-07。
>
> 状态：界面重构、自动化回归和 Windows 人工验收均已完成；本版本没有单独生成
> Release ZIP，也未作为公开发行版发布。
>
> 分类：交付。

## 1. 完成结论

MediaHub 0.3.0 在 v0.2 播放和直播能力之上，完成本地音频、本地视频和直播三种
界面模式重构。三种模式共享原有控件、模型、Presenter 命令和播放内核，只调整视觉
属性、信息层级、布局密度与响应式尺寸，不复制参考产品的商标、图片、字体或图标。

阶段 A 至 D、Debug/Release 全量测试、100%/125%/150% 模拟缩放以及真实长直播清单
和播放中窗口缩放均已通过。用户于 2026-08-07 确认当前版本无问题，v0.3 按本地
自用版本完成。

## 2. 已完成能力

- 本地音频使用浅色低饱和绿色音乐界面，真实 PCM 波形、歌词页和控制区保持统一
  视觉语言。
- 本地视频使用冷黑影院画布；活动视频继续由 libVLC 输出，Qt 不覆盖视频帧。
- 直播模式使用紧凑深色工具侧栏，把远程清单地址、载入、定位、连接状态和频道列表
  收拢到同一区域。
- 本地与直播列表往返时保持相同宽高和字号，侧栏宽度与字号随窗口尺寸响应式调整。
- 最小窗口、`960x720`、`1200x800`、全屏及三档模拟缩放均纳入 GUI 回归。
- 音量、倍速、跳转秒数和播放模式悬浮层继续向上展开，并在移动或缩放窗口后跟随
  对应按钮。
- 完成后的辅助视觉归档包括历史直播源窗口的石墨黑与暖金主题，以及快捷键帮助窗口
  的高对比“确定”按钮。

## 3. 保持不变的行为

- 播放/暂停、停止、上一首、下一首、刷新、定位、音量、歌词、倍速、播放模式和
  全屏仍由原有 Presenter 路由。
- 本地列表的多选、拖放、排序、重命名和移出，以及直播列表的只读与右键规则不变。
- `F5` 仍只刷新当前直播，`F11`、`Esc`、空格和方向键保持原语义。
- 三种模式切换不重建关键控件、不重复连接信号，也不额外发送播放或定位命令。
- 核心层、GUI 支持层和 libVLC 内核的依赖方向与线程边界没有变化。

## 6. 交付边界与已知限制

- 本版本按同一台 Windows x64 开发机上的本地自用标准完成，没有单独发布目录、ZIP
  或哈希；不得把 v0.2 的发布包标识当作 v0.3 产物。
- 100%/125%/150% 自动化使用 Qt 模拟缩放；其他 Windows 设备上的系统级 DPI 仍是
  跨环境补充验证，不影响本地自用结论。
- 自动化不能评价整体审美、真实视频合成和直播源质量，这些项目只引用已完成的人工
  验收证据，不表述为通用环境保证。
- v0.2 的网络来源、隐私、格式和协议限制继续有效；v0.3 没有扩大媒体处理范围。
