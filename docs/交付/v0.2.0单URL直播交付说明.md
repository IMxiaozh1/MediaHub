# MediaHub 0.2.0 单 URL 直播交付说明

> 本机验收日期：2026-08-06。
>
> 状态：单 URL 直播源码增量、构建矩阵和实机验收全部通过；未生成新的公开发布包。
>
> 分类：交付。

## 1. 交付结论

MediaHub 0.2.0 在 v0.1 本地播放能力之上完成用户自带直播 URL 的打开、连接状态、
主动取消、15 秒超时、手动刷新和会话内最近地址。正常直播、慢连接、直播与本地
MP3/MP4 往返、全屏和播放中关闭均已完成本机实测。公网 HLS/HTTP-FLV 兼容性复验
确认不同直播源的卡顿信号无法可靠统一判断，因此最终取消自动重连，由用户通过按钮
或 `F5` 主动刷新；直播切回本地歌曲后声音立即恢复。

本次交付更新源码版本元数据、文档和本地 Debug/Release 构建，不重新生成或发布
Windows ZIP。v0.1.0 的本地发布目录和哈希不代表 v0.2.0 产物。

## 2. 已交付能力

- 支持用户输入 `http`、`https`、`rtsp`、`rtmp`、`rtmps`、`udp`、`rtp` 和 `srt`
  绝对直播地址。
- 网络连接显示缓冲百分比；15 秒未播放时显示超时并允许重试。
- 连接期间停止立即取消，慢连接或旧播放器回收不阻塞 GUI。
- 网络直播显示“刷新直播”按钮；播放、缓冲、失败或普通画面停顿时，点击按钮或按
  `F5` 都会重开当前地址。明确失败或结束只提示刷新，不执行自动重连。
- 刷新复用当前列表项，不新增播放列表记录或最近地址；本地媒体不显示按钮，按 `F5`
  不执行播放命令。
- 网络媒体始终保持直播语义，即使源报告有限时长或可定位窗口，也显示 `--:--` 并
  禁用进度定位。
- 跨媒体切换使用独立 libVLC 实例；旧播放器后台关闭音视频轨并停止，新播放器继承
  音量和静音状态，进入播放后再次应用，避免直播切回歌曲时暂时无声。
- 当前进程最多保留 10 条最近地址，去重且最近优先；重启后清空。
- 完整 URL 的凭据、查询参数和片段不进入列表显示名、错误提示或结构化日志。
- 本地 MP3/MP4、歌词、波形、播放列表、进度、音量、定位和全屏行为保持正常。

## 4. 安全与范围边界

- 程序不内置、搜索、抓取、测速或托管任何第三方直播地址。
- 用户负责确认直播地址与内容来源合法；MediaHub 不绕过登录、DRM 或访问限制。
- 测试流、真实媒体、用户地址、缓存和本机构建产物均不提交到仓库。
- 会话内最近地址不持久化；完整 URL 可能包含敏感信息，不应进入公开日志或截图。
- 本次没有交付频道库、M3U 导入导出、远程订阅、Logo、EPG 或直播录制。
