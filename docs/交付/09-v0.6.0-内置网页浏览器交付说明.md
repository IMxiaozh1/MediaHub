## 3. 已交付浏览器能力

- 地址栏在导航完成后仍可编辑；点击或 `Ctrl+L` 会选中旧地址，提交地址复用当前标签。
- 顶部浏览器标签支持切换、拖动和关闭；`window.open` 与新窗口请求转为共享 Profile 的
  新标签，每个标签独立维护 WebView、地址、标题和前进/后退状态。
- 关闭标签不影响其他页面；关闭最后一个标签后保留内部空白页。
- 浏览历史按 URL 去重并限制 500 条；收藏夹支持标题、备注、编辑、删除并限制 5000 条。
  两者使用 MediaHub 浏览器专用 `QSettings` 跨重启保存。
- 历史和收藏普通点击复用当前标签，`Ctrl+点击` 或鼠标中键在新标签打开。
- 密码、Cookie、Token、LocalStorage 和 IndexedDB 不写入 `QSettings` 或日志；密码和
  自动填充由 WebView2 专用 Profile 管理。
- “清除网页数据”使用 `ALL_PROFILE` 清除 Cookie、LocalStorage、IndexedDB、缓存、
  已保存密码和自动填充数据，并清除当前会话证书例外；Edge 资料不受影响。

## 6. 数据与安全边界

- 网页功能是嵌入式浏览器能力，不接入播放器播放列表、最近播放、断点或直播数据。
- MediaHub 使用独立 WebView2 Profile；不读取、写入或删除 Edge Profile。
- 浏览历史与收藏只保存清理后的 URL、标题、访问时间和用户备注，不保存 URL 用户信息、
  查询、片段、密码、Cookie 或 Token。
- 生产日志只记录固定事件类别和 HRESULT 等诊断值，不记录完整 URL 或浏览器资料路径。
- Evergreen WebView2 Runtime 是系统前置条件，不随包复制 Edge 用户资料。
