# MediaHub 第一版 MVP

> 状态：v0.1 开发中，阶段 5 已完成。
>
> 分类：规划。
> 本文档定义第一版的具体行为、边界和可验证的验收用例。
> 实现方案见 [02-v0.1-实现设计.md](../设计/02-v0.1-实现设计.md)。

## 1. 一句话范围

一个 Windows Qt Widgets 桌面程序，能够打开并播放本地音频和视频文件，提供播放
控制、进度、音量和播放列表，并在失败时给出明确原因。

第一版不接触任何网络地址。

## 2. 输入

### 2.1 支持的输入方式

| 方式 | 说明 |
|---|---|
| 菜单“打开文件” | 通过系统文件对话框选择一个或多个文件 |
| 拖放 | 将文件从资源管理器拖入主窗口 |
| 命令行参数 | 启动时传入文件路径，直接加入列表并播放 |

三种方式最终都转换为同一种内部媒体项，不产生两套逻辑。

### 2.2 支持的文件类型

第一版按“内核能播就播”的原则处理，不维护自己的白名单。文件对话框提供的筛选
条件用于方便用户，不构成能力承诺。

对话框筛选条件初定为：

```text
音频文件 (*.mp3 *.flac *.wav *.aac *.m4a *.ogg *.wma)
视频文件 (*.mp4 *.mkv *.avi *.mov *.wmv *.flv *.ts)
所有文件 (*.*)
```

用户选择“所有文件”并打开一个非媒体文件时，程序必须给出失败提示，而不是崩溃。

### 2.3 路径要求

- 必须支持中文路径。
- 必须支持含空格的路径。
- 必须支持长路径和嵌套目录。
- 路径在内部统一使用 UTF-8 保存，只在调用系统接口时转换。

## 3. 播放控制行为

| 操作 | 前置状态 | 行为 |
|---|---|---|
| 播放 | 已停止或已暂停 | 从当前位置开始输出 |
| 暂停 | 播放中 | 保持位置，停止输出 |
| 继续 | 已暂停 | 从暂停位置继续 |
| 停止 | 播放中或已暂停 | 位置归零，画面清空 |
| 上一首 | 列表中有前一项 | 切换并按当前播放状态决定是否自动播放 |
| 下一首 | 列表中有后一项 | 同上 |
| 拖动进度 | 媒体可定位 | 跳转到目标位置并保持原播放状态 |
| 调节音量 | 任意 | 立即生效，范围 0 至 100 |
| 静音 | 任意 | 切换静音，不改变音量数值 |

## 4. 播放列表行为

- 列表保存媒体项的顺序、路径和显示名称。
- 重复添加同一路径时按追加处理，不做去重。
- 双击列表项立即切换并播放该项。
- 当前项播放结束后，按播放模式决定下一步。

播放模式第一版提供三种：

| 模式 | 行为 |
|---|---|
| 顺序播放 | 播放到列表末尾后停止 |
| 列表循环 | 播放到末尾后回到第一项 |
| 单曲循环 | 重复当前项 |

随机播放不在第一版范围内。

## 5. 状态与提示

程序对外表达以下播放状态：

| 状态 | 含义 |
|---|---|
| 空闲 | 没有加载任何媒体 |
| 打开中 | 正在加载媒体，尚未开始输出 |
| 缓冲中 | 内核正在准备数据（本地文件通常极短） |
| 播放中 | 正在输出音频或视频 |
| 已暂停 | 保持位置且停止输出 |
| 已停止 | 媒体仍然加载，位置归零 |
| 播放结束 | 当前项自然播放完毕 |
| 播放失败 | 内核报告错误，附带失败原因 |

失败提示必须说明是哪一个文件失败，以及失败的大致类别（文件不存在、无法解析、
不支持的编码、设备不可用）。提示不得只显示内核返回的原始英文错误码。

## 6. 界面草图

```text
┌────────────────────────────────────────────────────────────┐
│ 文件(F)  播放(P)  帮助(H)                                  │
├──────────────────────────────────────┬─────────────────────┤
│                                      │ 播放列表            │
│                                      │ ▶ 1. 示例音频.mp3   │
│            视频输出区域              │   2. 示例视频.mp4   │
│         （音频播放时显示占位）       │   3. ...            │
│                                      │                     │
│                                      │                     │
├──────────────────────────────────────┴─────────────────────┤
│ 00:42 ├────────●──────────────────────────────┤ 04:15      │
│ [上一首] [播放/暂停] [停止] [下一首]   音量 ├──●───┤ [静音] │
├────────────────────────────────────────────────────────────┤
│ 状态：播放中 — 示例音频.mp3                                │
└────────────────────────────────────────────────────────────┘
```

界面第一版使用系统原生样式和布局管理器，不使用固定像素坐标。主窗口应能在
Windows 100%、125% 和 150% 缩放下正常使用。

## 7. 验收用例

以下用例编号在阶段测试文档中直接引用。全部成立才算 MVP 完成。

### 基础播放

- **M-01** 打开一个正常音频文件，点击播放，能听到声音，进度前进。
- **M-02** 打开一个正常视频文件，点击播放，画面和声音同时输出。
- **M-03** 播放中点击暂停，输出停止且进度保持不变。
- **M-04** 暂停后点击播放，从暂停位置继续，不从头开始。
- **M-05** 播放中点击停止，进度归零，视频区域清空。

### 定位与音量

- **M-06** 拖动进度条到中段，播放位置跳转到目标位置附近。
- **M-07** 暂停状态下拖动进度，位置改变但仍保持暂停。
- **M-08** 调节音量，输出音量随之变化，数值显示同步更新。
- **M-09** 点击静音，声音消失；再次点击恢复到原音量数值。

### 播放列表

- **M-10** 一次选择多个文件，全部按选择顺序加入列表。
- **M-11** 拖放多个文件进窗口，效果与菜单打开一致。
- **M-12** 双击列表中的第三项，立即切换并播放该项。
- **M-13** 顺序播放模式下播放完最后一项，程序停止且不报错。
- **M-14** 列表循环模式下播放完最后一项，回到第一项继续。
- **M-15** 单曲循环模式下播放完当前项，重新播放同一项。

### 错误处理

- **M-16** 打开一个不存在的路径，显示失败提示，程序保持可用。
- **M-17** 打开一个内容损坏的媒体文件，显示失败提示，不崩溃。
- **M-18** 打开一个纯文本文件并改名为 `.mp4`，显示失败提示，不卡死。
- **M-19** 列表中某一项失败后，仍可手动切换到其他项正常播放。

### 路径与编码

- **M-20** 播放路径包含中文和空格的文件，正常播放且显示名称正确。

### 生命周期

- **M-21** 播放中直接关闭窗口，进程正常退出，不残留后台进程。
- **M-22** 快速连续切换多个媒体项，不崩溃、不死锁、状态最终一致。

## 8. 明确不在验收范围

- 网络地址、直播流和任何联网行为。
- 字幕、多音轨、倍速、截图和录制。
- 媒体库、播放历史和收藏。
- 精确到帧的定位精度保证。
- 特定冷门编码格式的播放能力承诺。
- 音画同步质量的量化指标。第一版由内核负责同步，不做自研同步逻辑。

## 9. 退出与错误分类

| 类型 | 示例 | 处理 |
|---|---|---|
| 用户输入错误 | 选择了不存在或非媒体文件 | 提示原因，程序继续运行 |
| 内核可恢复错误 | 单个媒体项打开失败 | 记录并提示，其他项不受影响 |
| 设备错误 | 没有可用音频输出设备 | 提示原因，允许继续操作界面 |
| 致命内部错误 | 无法初始化播放内核 | 启动阶段提示并退出，返回非零退出码 |

正常退出返回 `0`。播放内核初始化失败返回 `1`。第一版不定义更细的退出码。
