# MediaHub v0.4 状态持久化与快捷键

> 状态：实现、自动化与本地人工验收均已完成。
>
> 启动日期：2026-08-07。
>
> 分类：规划。

## 1. 版本目标

v0.4 让用户关闭并重新打开 MediaHub 后继续看到上次的本地播放列表和直播清单
URL，同时补齐明确的全屏、静音与帮助入口。恢复状态只用于展示和下一次操作，程序
启动时不得自动打开、解析或播放任何媒体；用户手工记录的直播源地址和备注也只作为
本机保存的资料，不与现有播放列表混合。

## 2. 功能范围

1. 持久化本地播放列表的顺序、源路径和列表内显示名；新增、移出、排序和重命名后
   同步保存。
2. 持久化直播清单编辑框最后一次 URL；启动后只回填编辑框，不自动载入清单。
3. 成功载入的直播清单 URL 进入最近历史，按最近使用排序、去重并最多保留 20 项。
4. URL 编辑框右侧增加纯图标历史按钮，可访问名称和悬停提示均为“历史直播源”。
5. 历史按钮打开独立对话框；用户可把所选 URL 回填编辑框、删除历史项或取消。
   回填本身不得触发网络请求，仍由“载入 / 刷新清单”执行解析。
6. 清单载入期间原按钮切换为“取消载入”，取消后忽略迟到结果并保留旧直播列表。
7. `F11` 在窗口与全屏之间双向切换，`Esc` 继续退出全屏。
8. `Ctrl+下键` 明确静音，`Ctrl+上键` 明确恢复声音；重复请求同一状态不重复发送
   内核命令。`Ctrl+F5` 不分配功能，单独 `F5` 继续刷新当前直播。
9. 菜单栏增加“帮助 → 快捷键”，独立窗口列出当前实际支持的快捷键，点击“确定”
   返回主窗口。
10. “帮助”下增加第二个选项“直播源”，打开独立两列窗口，第一列编辑直播源地址，
    第二列编辑备注；窗口使用红色提示说明其用途，并提供醒目的新增、删除、返回和
    保存按钮。
11. 点击保存或在直播源窗口内按 `Ctrl+S` 时先询问是否保存；确定后写入本机配置，
    取消则保留未保存编辑。`Ctrl+S` 仅在该窗口及其子控件内生效，并加入快捷键帮助。
12. 有未保存编辑时点击返回或窗口 `X`，统一询问是否保存；选择是则保存并关闭，
    选择否则放弃本次编辑并关闭。没有修改时直接关闭。

## 3. 设计边界

- 持久化接口位于 GUI 支持层，可由主程序注入 `QSettings` 实现；普通 GUI 测试默认
  不启用持久化，专用测试注入内存或临时 INI 存储，避免用例互相污染。
- `mediahub_core` 不依赖 Qt，`mediahub_gui_support` 不链接 libVLC，`main.cpp` 只负责
  组装真实存储、窗口、Presenter 和播放内核。
- 本地媒体路径和完整直播 URL 只写入用户本机配置，不进入日志和仓库。删除历史只
  删除配置记录，不访问或修改用户媒体文件。
- “帮助 → 直播源”只承担地址和备注的资料保存，不解析、不载入、不播放，也不替代
  或修改现有“本地列表 / 直播列表”。
- 恢复列表时不得调用 `PlayerEngine::open()`、直播清单服务或歌词服务。
- 保留 `livePlaylistUrlEdit` 等现有对象名和 Presenter 信号路由契约。

## 4. 自动化验收

| 编号 | 验收项 |
|---|---|
| P-01 | 临时 INI 能无损往返中文路径、列表显示名、最后 URL 和历史顺序 |
| P-02 | 新 Presenter 恢复本地列表和 URL，但假内核与清单服务均收到零个打开请求 |
| P-03 | 本地列表新增、移出、排序和重命名后的快照与界面一致 |
| P-04 | 成功清单 URL 最近优先、去重且限制 20 项；失败 URL 不进入成功历史 |
| P-05 | 历史窗口回填不载入，删除会持久化，取消不会改变编辑框 |
| P-06 | 清单取消立即恢复按钮和状态，迟到成功或失败不替换当前列表 |
| P-07 | `F11` 连按完成进入和退出全屏，`Esc` 仍可退出 |
| P-08 | `Ctrl+下/上` 分别静音/恢复且幂等，`Ctrl+F5` 不刷新也不改变静音 |
| P-09 | 帮助菜单能打开完整快捷键窗口，确定按钮安全返回 |
| P-10 | Debug/Release 全量 CTest 通过，启动、播放、直播和关闭行为无回归 |
| P-11 | 临时 INI 无损往返中文直播源地址和备注，日志不包含完整地址 |
| P-12 | “帮助”下同时包含快捷键和直播源；两列表格、红色提示及高对比按钮存在 |
| P-13 | 保存取消、`Ctrl+S` 确认保存、返回放弃和 `X` 保存关闭均符合规则且不触发播放 |

## 5. 人工验收

1. 添加并调整本地列表，关闭后重新启动，确认列表顺序和显示名恢复且没有自动播放。
2. 成功载入两个直播清单，重启后确认最后 URL 回填；历史窗口可选择、删除和取消。
3. 播放本地媒体和直播时验证全屏、静音、恢复、单独 `F5` 刷新及帮助窗口。
4. 在“帮助 → 直播源”中新增地址和备注，分别验证保存按钮、`Ctrl+S`、返回和 `X`
   的确认流程；重启后记录恢复，现有播放列表保持不变。
