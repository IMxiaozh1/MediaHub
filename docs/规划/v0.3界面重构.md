# MediaHub v0.3 界面重构

> 状态：实现、自动化与本地人工验收均已完成。
>
> 启动日期：2026-08-07。
>
> 分类：规划。
> 本版本只重构界面层级、视觉样式和响应式布局，不改变播放功能、命令路由或媒体
> 处理逻辑。

## 1. 版本目标

v0.3 为本地音频、本地视频和直播播放建立三种有明确区分、但共享同一套控件语义的
界面形态：

| 场景 | 参考方向 | MediaHub 中采用的视觉语言 |
|---|---|---|
| 本地音频 | QQ 音乐 | 明亮留白、柔和绿色强调、沉浸歌词和音频可视化 |
| 本地视频 | 腾讯视频 | 深色影院画布、克制的青绿色强调、控制信息贴近播放区域 |
| 直播流 | PotPlayer | 深色紧凑工具面板、高密度频道列表、清晰的连接与刷新状态 |

参考只用于提取信息层级、密度和色彩气质，不复制商标、图标、图片、字体文件或像素级
布局。项目继续使用自绘图标和系统可用字体，不新增第三方视觉资源。

## 2. 不可改变的交互契约

重构期间以下行为必须保持不变：

1. 播放/暂停、停止、上一首、下一首、刷新直播、音量、静音、歌词、倍速、跳转秒数、
   播放模式、全屏和播放列表折叠仍发送现有信号，由 `PlayerPresenter` 决定业务规则。
2. 空格、方向键、`Ctrl+左/右`、`F5`、`F11`、`Esc`、`Ctrl+O` 和 `Ctrl+L` 的含义
   不变。
3. 音量、倍速、跳转秒数和播放模式的悬浮层继续向上展开，不抢占播放窗口焦点。
4. 本地列表继续支持多选、拖放、双击、排序、重命名和移出；直播列表继续保持只读，
   右键播放/暂停、停止、标记和收藏规则不变。
5. 直播清单的载入、失败保留、定位正在播放、不可用标记及滚动位置保护不变。
6. 全屏时播放控制继续可见，退出全屏后恢复原布局；关闭窗口仍先解绑视频句柄再停止。
7. 控件现有 `objectName`、可访问名称和 Presenter 连接视为兼容接口，除非测试先明确
   更新，否则不得改名或绕过。

## 3. 界面结构

```text
主窗口
├── 场景标题栏：当前模式、主标题、辅助说明和状态标识
├── 播放工作区
│   ├── 媒体画布：视频、音频波形或歌词
│   ├── 列表折叠按钮
│   └── 播放列表面板：本地列表或直播工具面板
├── 当前媒体信息条：名称、状态和内联错误
└── 播放控制台：时间、进度和全部既有功能按钮
```

三种场景只改变视觉属性、文字层级和控件密度，不创建三套业务页面。窗口从
`PlayerViewState` 推导展示模式，继续使用同一组控件和信号连接，避免视觉分支演变为
业务分支。

## 4. 视觉规范

### 4.1 本地音频

- 使用浅灰白背景、低饱和绿色和少量青色光晕，避免原界面的米黄与棕色组合。
- 波形和当前歌词使用明亮绿色强调，正文保持高对比深灰。
- 列表与控制台采用轻量卡片，不使用粗重边框；当前媒体信息优先于技术状态。
- 歌词页与波形页共享同一背景气质，切换时不产生明显的主题跳变。

### 4.2 本地视频

- 媒体画布使用接近黑色的影院背景，窗口外围使用冷灰蓝层次。
- 控制台与媒体信息紧邻画布，播放按钮使用青绿色主强调，其余按钮保持低干扰。
- 播放列表使用深灰侧栏，当前项、悬停项和禁用项必须可区分。
- 视频输出仍由 libVLC 绘制，Qt 样式不得覆盖活动视频帧。

### 4.3 直播流

- 使用接近 PotPlayer 工具界面的深灰层级，缩小圆角和垂直间距，提高频道可见数量。
- 直播清单地址、载入、定位、连接状态和频道列表集中在同一侧栏内。
- 直播刷新和连接状态使用暖黄色强调；播放主按钮仍保持全局青绿色语义。
- 收藏、不可用和当前播放三个状态必须能同时表达，不通过自动滚动破坏用户位置。

### 4.4 辅助直播窗口

- 历史直播源窗口使用石墨黑、暖金色和低饱和红色，分别表达信息区、主操作和删除。
- 历史地址选中态必须清晰，取消操作保持低干扰，“使用所选”作为唯一视觉主按钮。
- 快捷键帮助窗口的“确定”按钮必须与深绿背景明显分离，并保持足够大的点击区域。

## 6. 自动化验收

| 编号 | 验收项 |
|---|---|
| U-01 | 初始窗口使用本地视频展示模式，所有既有控件仍可按原对象名查找 |
| U-02 | 打开本地音频后切换为音频模式，播放命令和波形行为不变 |
| U-03 | 打开本地视频后切换为视频模式，原生视频句柄与全屏行为不变 |
| U-04 | 打开直播后切换为直播模式，刷新、停止和不可定位语义不变 |
| U-05 | 三种模式切换不重复连接信号，不额外产生播放、定位或音量命令 |
| U-06 | 最小尺寸下进度条和全部控制按钮仍在窗口内，进度条宽度不少于 100px |
| U-07 | 列表折叠/展开会调整画布尺寸，不改变当前媒体和列表选择 |
| U-08 | 悬浮层在三种模式下均向上展开，移动或缩放窗口后继续跟随触发按钮 |
| U-09 | 本地和直播右键菜单的启用规则、命令路由及滚动保护全部保持原行为 |
| U-10 | 全量 CTest 通过，模块依赖边界和关闭时序无回归 |

## 7. 人工验收

自动化不能判断整体美感和真实视频合成效果，以下项目明确保留人工确认：

1. 音频页是否具有轻盈、专注内容的音乐播放器观感，歌词和波形是否协调。
2. 视频页是否形成深色影院层级，活动画面周围没有亮色干扰或 Qt 重绘覆盖。
3. 直播页在真实长清单下是否紧凑易扫读，状态、收藏和不可用标记是否清楚。
4. 125%/150% Windows 实际缩放及全屏切换时，文字、按钮和弹层是否清晰稳定。

人工验收已完成；详细证据和仍需在其他 Windows 缩放环境补充的风险见测试文档。
