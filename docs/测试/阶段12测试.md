## 1. 交付实现

- `MEDIAHUB_PACKAGE_RELEASE=ON` 启用 Windows Release 安装规则，日常开发构建不受影响。
- `cmake --install` 只复制 `MediaHub.exe`、Qt Release 运行库、libVLC 两个 DLL、完整
  VLC 插件目录和许可证材料，不复制测试程序、静态库或构建中间文件。
- `windeployqt` 固定使用目标 Qt 套件中的工具，并使用 `--release`、
  `--no-translations` 和 `--no-compiler-runtime`。目标机必须预装 VC++ 2015-2022
  Redistributable（x64）。
- `tools/validate_release_package.cmake` 检查必需文件、VLC 插件数量，并拒绝 `.lib`、
  `.obj`、`.pdb`、Debug DLL、测试产物和 VC++ 安装器。
- `tools/stage12_isolated_smoke.ps1` 清空 Qt/VLC 环境变量、把 PATH 缩减为 Windows
  系统目录，播放真实媒体后检查响应、依赖来源和正常退出码。

## 4. 隔离运行

以真实 `乌兰图雅 - 套马杆.mp3` 执行 100%、125% 和 150% 三次隔离冒烟：

1. 清空 `QT_PLUGIN_PATH`、`QML2_IMPORT_PATH` 和 `VLC_PLUGIN_PATH`。
2. 设置 PATH 只包含 Windows 与 System32。
3. 从发布目录启动，自动打开并播放 5 秒。
4. 确认进程存活且界面响应。
5. 确认 Qt5Core/Gui/Network/Widgets 与 libvlc/libvlccore 均从发布目录加载。
6. 请求正常关闭，10 秒内退出且退出码为 `0`。

三档缩放均通过。用户随后分别检查强制 125% 和 150% 发布版的控制行、播放列表、
歌词、全屏和悬停弹层，均确认没有问题。该结果仍不替代修改 Windows 系统显示缩放
后的完整复测。

## 5. 许可证结论

- 发布目录包含 Qt LGPLv3、Qt GPLv3、VLC 官方 `COPYING.txt` 和第三方说明。
- Qt 与 VLC 均动态链接，发布目录结构允许用户替换兼容运行库。
- 当前复制 VLC 官方完整插件目录，其中可能包含 GPL 插件；本包当前只用于本地验证。
  对外公开分发前必须逐项复核并裁剪或按 GPL 要求交付。
- MediaHub 自身源码许可证尚未决定，已在第三方说明中明确；当前材料不构成公开再分发
  授权。
