## 3. 结果记录

2026-08-05 自动化结果：

- `cmake-build-debug` 全量 CTest `48/48` 通过，用时约 19.45 秒。
- `cmake-build-core-debug` 核心独立 CTest `33/33` 通过，用时约 0.99 秒。
- GUI 套件包含合法/非法网络地址、隐私化列表名称与日志、自动播放请求、未知时长和
  不可定位进度条用例，完整套件通过。
- libVLC 集成测试确认合法网络源可创建媒体描述，非法网络源会安全拒绝且错误中不
  泄漏完整 URL。

2026-08-05 人工验收过程：

- 初次使用 Python `SimpleHTTP` 暴露普通 MP4。该服务对 VLC 的 `Range` 请求错误
  返回 `200` 全文件，且测试 MP4 的 `moov` 索引位于 `mdat` 后；VLC 诊断明确记录
  `stream is not seekable`，因此媒体被快速读完并显示“播放结束”。这属于测试服务
  不支持分段读取，不是 MediaHub 提前结束网络媒体。
- 随后改用本机 VLC 将同一测试视频循环封装为 MPEG-TS，通过
  `http://127.0.0.1:18766/live.ts` 持续输出。三秒探测收到 HTTP `200` 和约 889 KiB
  连续数据。
- 用户从“打开网络地址”输入 MPEG-TS 地址后确认不再出现刚打开就结束。首次网络
  音频输出未同步界面初始音量，且直播误用了本地文件为平滑倍速准备的 `1.001×`
  热启动；修复为直播 `1.0×` 原速，并在进入 `Playing` 后同步音量与静音状态。
- 用户复验确认网络视频“画面和声音都有了”。播放期间音量悬浮框改为相对音量按钮
  左移 16px、向下重叠 4px，并以 500ms 延迟收起；用户多轮移动和调节后确认正常。
- MP3 总时长出现或窗口布局变化后，音量悬浮框会继续跟随音量按钮；用户于
  2026-08-05 复验确认位置正常。
- 播放列表右键菜单新增暂停和停止。当前项播放中时播放置灰，暂停后暂停置灰，停止后
  只保留播放；右键其他项只允许播放，多选仍只允许移出列表。自动化覆盖上述状态切换。
- 停止按钮、连接期间窗口移动缩放和本地媒体往返仍保留为后续完整 v0.2 人工回归
  项，不阻塞第一增量封存。
