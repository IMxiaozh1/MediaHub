## 4. 发现与修正

首次全量 GUI 回归发现：为了支持“内核未发 `Opening` 就取消”而放宽的
`Idle -> Stopped` 会接受移除列表项后的迟到停止事件，导致空列表显示
“已停止”。最终保持核心状态机原有边界，由 Presenter 独立表示网络取消状态，
并补充空列表与计时器回归用例。

第一次真实慢连接验收又发现：从正在播放的 HTTP 直播切换到慢连接时，
libVLC 3 同步停止旧流会卡住 GUI，即使慢服务关闭也不会立即恢复。修正后，
所有真实内核控制命令在专用线程串行执行；网络停止和切换通过新播放器
立即接管，旧实例后台回收。用户复验确认窗口不再卡死，取消后也可恢复正常
直播。最终 Debug 全量 `49/49` 通过。
