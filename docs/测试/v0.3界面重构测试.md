# MediaHub v0.3 界面重构测试

> 状态：进行中，阶段 A、B、C 已完成。
>
> 最后更新：2026-08-07。
>
> 分类：测试。

## 1. 测试目标

界面重构必须证明两件事：三种场景具有独立且稳定的视觉模式；视觉切换没有改变现有
播放、列表、快捷键、悬浮层、全屏和关闭时序。自动化只验证可客观判断的结构与行为，
整体美感、真实画面合成和 Windows 实际 DPI 继续由人工验收。

## 2. 阶段 A：主题基础与控件契约

### 2.1 实现范围

- 新增独立主题模块和本地音频、本地视频、直播三种展示模式。
- 主窗口标题区改为场景标题栏，主题通过动态属性应用到既有控件。
- 保留全部既有 `objectName`、信号连接、Presenter 路由和快捷键。
- 新增模式往返测试，验证关键控件不会因换肤被销毁或替换。

### 2.2 自动化结果

| GUI 套件 | CTest `gui.stage10_coverage` | 通过，包含新增模式往返场景 |

`cl.exe` 无法取得 MSVC 标准库 `INCLUDE`；这属于本机环境要求，不是代码缺陷。

## 3. 阶段 B：本地音频与视频

### 3.1 实现范围

- 音频画布改为浅色低饱和绿色背景，保留真实 PCM 波形、动画和进度计算。
- 歌词页统一为浅绿音乐主题，保留同步歌词、普通歌词和时间校准行为。
- 视频占位改为深色影院背景；活动视频时继续跳过 Qt 绘制，不覆盖 libVLC 帧。
- Windows 标题栏随音频/视频模式切换亮色或深色，不影响窗口句柄和关闭时序。
- 列表标签缩短为“本地列表 / 直播列表”，避免紧凑侧栏内文字被裁剪；索引和路由不变。

### 3.2 自动化结果

| Release GUI 构建 | `cmake --build cmake-build-release --target mediahub_gui mediahub_gui_tests` | 通过 |
| Release 全量测试 | `ctest --test-dir cmake-build-release --output-on-failure` | `72/72` 通过，22.64 秒 |
| GUI 套件 | CTest `gui.stage10_coverage` | 通过，8.48 秒 |

全量 GUI 套件同时回归原有歌词、倍速、定位、全屏、列表折叠、悬浮层和关闭路径；

### 3.3 开发侧视觉检查

使用仓库外 `test.mp3` 启动最新 Release，确认浅色标题栏、绿色波形、轻量卡片、底部
控制台及“本地列表 / 直播列表”标签完整显示。截图只保存在已忽略的构建目录，不纳入
版本控制。整体审美和真实视频画面仍等待最终人工验收，不据此标记 v0.3 交付完成。

## 4. 阶段 C：直播工具界面

### 4.1 实现范围

- 把远程清单地址、载入、定位和状态收拢到独立信号源工具区。
- “载入 / 刷新清单”和“定位正在播放”改为同行紧凑操作，按钮对象和信号不变。
- 直播频道侧栏缩小边距和行距，使用暖黄色状态、方形控制和窄滚动条。
- 本地与直播标签切换时只切换工具区可见性、标题和布局密度，不重建列表或控件。
