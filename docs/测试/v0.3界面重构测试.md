# MediaHub v0.3 界面重构测试

> 状态：阶段 A 至 D 的实现、自动化与本地人工验收均已完成。
>
> 最后更新：2026-08-07。
>
> 分类：测试。

## 1. 测试目标

界面重构必须证明两件事：三种场景具有独立且稳定的视觉模式；视觉切换没有改变现有
播放、列表、快捷键、悬浮层、全屏和关闭时序。自动化只验证可客观判断的结构与行为，
整体美感、真实画面合成和 Windows 实际 DPI 继续由人工验收。

## 2. 阶段 A：主题基础与控件契约

### 2.1 实现范围

- 新增独立主题模块和本地音频、本地视频、直播三种展示模式。
- 主窗口标题区改为场景标题栏，主题通过动态属性应用到既有控件。
- 保留全部既有 `objectName`、信号连接、Presenter 路由和快捷键。
- 新增模式往返测试，验证关键控件不会因换肤被销毁或替换。

## 3. 阶段 B：本地音频与视频

### 3.1 实现范围

- 音频画布改为浅色低饱和绿色背景，保留真实 PCM 波形、动画和进度计算。
- 歌词页统一为浅绿音乐主题，保留同步歌词、普通歌词和时间校准行为。
- 视频占位改为深色影院背景；活动视频时继续跳过 Qt 绘制，不覆盖 libVLC 帧。
- Windows 标题栏随音频/视频模式切换亮色或深色，不影响窗口句柄和关闭时序。
- 列表标签缩短为“本地列表 / 直播列表”，避免紧凑侧栏内文字被裁剪；索引和路由不变。

## 6. 人工验收结果

自动化不能替代整体审美、真实视频合成、长直播清单可扫读性和 Windows 系统级 DPI
检查。本轮最新 Release 的确认结果如下：

1. 用户确认本地列表与直播列表往返时宽度、高度和字号一致，扩大窗口后侧栏和列表
   字号同步增大。
2. 真实远程长清单载入 444 个频道后，频道区、工具区和状态信息可正常使用。
3. 一个可用频道进入播放后连续调整 `760x640`、`1200x800`、`960x720` 三档尺寸，
   画面、声音和程序响应保持正常；个别频道的 15 秒超时属于直播源或网络链路状态，
   不属于 resize 回归。
4. 100%、125% 和 150% 的完整 GUI 自动化均通过；Windows 系统级 DPI 在其他设备
   上的观感仍作为跨环境补充验证，不阻塞本地自用结论。

用户于 2026-08-07 确认当前版本无问题，v0.3 本地人工验收完成。
