## 1. 问题与根因

用户在深色模式下打开“快捷键”和“直播源备忘”窗口时，发现表头、普通行、表格空白区和
原生标题栏仍显示浅色。浅色区域会让深色文字或浅色文字失去对比度，直播源备忘进入编辑
状态时也存在继续继承错误背景的风险。

原实现只在顶层对话框样式表中声明 `QTableWidget` 和 `QHeaderView` 规则，并修改表格本身
的调色板。Qt 5 的表格视口、内部表头和委托编辑器是独立子控件；Windows 平台样式没有完整
继承这些声明，实际表头仍由系统绘制为 `#f2f2f2`，视口的基础色也可能回落为白色。窗口标题栏
属于 DWM 非客户区，更不受 Qt 样式表控制。

## 2. 修复策略

1. 为表格、viewport、水平/垂直表头的 Active、Inactive 和 Disabled 调色板统一设置窗口、
   基础色、交替色、文字、选中和按钮语义色。
2. 表格普通行和交替行直接声明当前主题的画布色与面板色；表头使用独立样式表，避免平台
   样式重新接管内部 `QHeaderView`。
3. viewport 使用对象名限定的背景规则，只填充表格空白区，不再把画布背景继续传给单元格
   编辑器；编辑器单独使用面板色、主题强调边框和选中文字颜色。
4. 抽取 Windows 原生深色标题栏入口，主窗口、两个帮助窗口及直播源确认框共用同一实现；
   浅色主题会明确恢复浅色标题栏。
