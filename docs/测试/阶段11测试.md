## 1. 本轮实现与缺陷修复

阶段 11 以真实验收为主。本轮人工操作暴露并修复了两个关联问题：

- 双击纯文本伪装的 `.mp4` 后，libVLC 会把它快速结束，顺序模式错误推进到下一项。
- 一次失败媒体关闭操作中，窗口已经消失，但 libVLC 释放竞态使进程留在后台。
- 暂停后第一次定位产生的 libVLC 缓冲事件覆盖了暂停状态，使进度条无法再次拖动。
- Qt 文件选择器在 Windows 上返回正斜杠路径，libVLC 3 无法据此创建本地媒体；一次
  失败打开还会清除上一媒体，表现为 MP4 无法播放且切回 MP3 后没有声音。

对应修复如下：

- MP4 预检能识别带 UTF-8 BOM 的纯文本内容，直接报告不支持格式，不交给 libVLC。
- Presenter 只有在当前媒体真正进入 `Playing` 后才接受结束事件推进列表，忽略切换后
  属于上一媒体的迟到结束事件。
- 用户请求关闭后启动三秒退出保护。正常情况下仍完整执行既有清理顺序；若第三方
  组件超时未返回，则只终止当前 MediaHub 进程，避免无窗口残留。
- 新增伪装文件无结束事件、迟到结束事件、退出保护超时执行与正常取消的回归测试。
- 播放或暂停已经稳定后忽略定位产生的缓冲事件，暂停状态可连续定位；GUI 与真实
  libVLC 集成测试都覆盖连续定位两次。
- 本地路径进入 libVLC 前转换为 Windows 原生分隔符，同时保持 UTF-8 中文路径；新增
  Qt 风格正斜杠路径集成测试，并用真实媒体验证 MP3、MP4、MP3 连续切换。
- 最后一项媒体自然结束时把当前位置固定为总时长，迟到的位置与时长事件不再把进度
  拉回；禁用状态仍保留清晰的末端手柄和已播放轨道。
- 新增可单击轨道定位的进度条；自然结束后进度条继续可用，点击或拖动会定位并
  自动重新播放。真实操作确认 libVLC 3 在 Ended 后直接 Play 可能无声且进度不动，
  因此播放按钮、空格和进度定位统一重新打开当前媒体，再执行 Play→Seek。
- 真实播放结束时 libVLC 会把 `isSeekable` 临时改为 `false`；结束状态改为只要总时长
  有效就允许定位，并新增该标记为 `false` 时点击和拖动仍能续播的回归测试。
- 部分真实播放还会在自然结束后补发 `Stopped`；Presenter 忽略该清理事件，保持
  “播放结束”、末端进度和可定位状态，不把它误判为用户主动停止。
- 新增窗口级键盘控制：空格切换播放/暂停，上下键每次调整音量 5%，左右键按界面
  配置的秒数后退或快进；跳转值固定为 5、10、15、20 秒，默认 5 秒。
- 倍速和跳转秒数使用向上展开的圆角悬停菜单；鼠标离开按钮与菜单后自动收起。
- 倍速增加 0.75× 档位；音量改为向上展开的竖向滑块，点击音量按钮仍可静音或
  恢复。音量、左右键跳转秒数和倍速均放在进度条右侧，不再单独占一行。
- 音量使用不抢占点击的独立悬浮面板，面板已显示时点击静音会保持原位，不再整框
  闪现；跳转和倍速无论悬停还是点击均固定向上展开。静音时滑块显示 0%，恢复时
  回到原音量，静音中调节会自动恢复。
- 轻按右键快进一次；长按时临时以固定 2.0 倍速播放并显示 2.0×，松开后恢复用户
  选择的实际倍速和显示值，系统键盘自动重复不会产生连续 Seek。
- 倍速请求在菜单完成交互后再交给 libVLC，并缓存最近一次已下发倍率；重复的播放状态
  不再重复调速，切换媒体后仍按用户选择重新应用，减轻倍速选择和长按切换时的卡顿。
- 曾把 VLC 3 `scaletempo` 的蓄帧窗口由默认约 50ms 压缩到约 15ms；人工验收发现
  倍速声音失真、清晰度下降，因此撤销该方案并恢复 VLC 默认的高质量参数。
- VLC 在精确 1.0 倍时会绕过 `scaletempo` 并清空其工作缓冲；底层以 VLC 可识别的
  最小偏移 1.001 倍保持滤镜热状态，界面仍按需求显示 1.0 倍。五分钟媒体的理论
  时长偏差约 0.3 秒，换取倍速选择和长按切换时不再从空缓冲启动。
- 曾尝试以多个中间倍率做平滑过渡；人工验收发现每个中间倍率都会触发音频重同步，
  高倍速切回低倍速时反而连续卡顿，因此已撤销。现在每次只下发一次最终倍率，保留
  同倍率去重和 `scaletempo` 热状态，避免把一次重同步放大成多次。
- 纯音频改倍率后在原位置重建输入时钟，用户确认 MP3 切换倍率已经流畅。视频不能复用
  该补偿，否则 MP4 会按关键帧跳转；视频现在不发 Seek，并把本地缓存从 VLC 默认约
  1000ms 缩到 30ms，减少倍率变化时被清空的旧帧和音频队列。用户确认画面和声音切换
  已无问题。
- 新增 `Ctrl+左/右` 切换上一首/下一首；带 Ctrl 的右键由长按过滤器主动放行，普通
  左右键的定位和长按 2.0 倍速行为保持不变。
- 悬停菜单弹出前再次校验鼠标真实位置，并在显示期间持续检查按钮和菜单区域；即使
  刚悬停就立刻移开，也会取消待弹出的菜单，不留下悬浮选项。
- 将进度条和全部播放控制合并为单行；上一首、播放/暂停、下一首、停止、音量、
  播放模式和全屏使用程序内绘制图标，播放/暂停、静音和全屏图标随状态切换。
- 音量悬浮框只显示百分比数值；点击静音时同步显示 0% 和静音图标，恢复时显示原音量。
- 播放模式从列表面板移入控制行，并在顺序、列表循环和单曲循环之外新增随机播放；
  随机模式在多项列表中不会立即再次选择当前项，单项列表自然结束时重播当前项。
- 全屏时保留控制行，同一个全屏按钮可再次点击退出；标题、媒体卡和播放列表隐藏。
- 视频区和播放列表之间新增折叠箭头；列表展开时箭头向右，折叠时箭头向左，音视频
  区域随列表隐藏或恢复自动伸缩。
- “打开文件”按钮移动到原“移出选中”位置。列表支持右键播放、仅列表内重命名、
  置顶、上移、下移和移出；`Ctrl` 支持独立多选，`Shift` 支持连续多选。多项右键时
  只开放移出列表，其他动作全部置灰；列表内重命名不改变原媒体路径或磁盘文件名。
- 125%/150% 自动化复验暴露音量和倍速悬停命中依赖全局光标坐标的问题；现改为跟随
  Qt 控件进入/离开事件，并直接模拟事件覆盖三档缩放，弹层不再受坐标缩放影响。
- 音量按钮调整到停止按钮右侧；倍速、跳转秒数和播放模式不再通过会抢占鼠标状态的
  `QMenu::popup()` 展开，统一使用音量同款的独立 Tool 悬浮窗，避免按钮持续悬停时
  菜单反复打开和关闭。
- 播放模式按钮每点击一次会按顺序、列表循环、单曲循环、随机播放循环切换；悬停
  列表保持显示，并立即把唯一勾选项同步到按钮刚切换的模式。
- 纯音频不再显示静态“没有视频画面”占位；独立 libVLC 实例中的辅助解码器从当前
  媒体取得真实单声道 PCM，不接管或争用主播放器的声音和时钟。全频、低频及瞬态
  合成为当前歌曲的声音强度，最多每 66ms 投递一次。
- 画布使用 192 点绘制一条位于底部、不横向移动的连续线，不保存或滚动历史；当前
  PCM 归并为 24 个圆滑控制段，只从底部基线向上形成疏密适中的高波峰，约 0.1 至
  0.3 秒完成快速升起和回落。
  左上角只保留文件名，移除画布内部进度条、百分比和说明，控制行主进度条保持不变。
- 音频画布缓存渐变、光晕和网格等静态背景，波形计算量固定为 192 点，不再随全屏
  宽度增加，也不再每帧重复构造和绘制三层双份路径。
- 音频在打开、缓冲、播放和暂停状态下可使用全屏按钮；同一个按钮进入和退出全屏，
  图标与语义同步，停止、结束或失败后仍按既有规则退出全屏。

测试媒体均位于用户路径或系统临时目录，只读使用，不复制、不修改、不提交到仓库。
