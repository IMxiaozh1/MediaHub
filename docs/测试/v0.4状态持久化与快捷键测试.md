# MediaHub v0.4 状态持久化与快捷键测试

> 状态：自动化与本地人工验收均已通过。
>
> 最后更新：2026-08-07。

## 1. 测试目标

验证状态能够跨进程保存但不会触发启动播放，历史窗口只负责选择和删除，快捷键和
帮助窗口与实际代码保持一致；直播源资料窗口只保存地址和备注，不进入播放链路。
完整用例编号见 `docs/规划/v0.4状态持久化与快捷键.md` 的 P-01 至 P-14。

## 2. 当前结果

P-01 至 P-09、P-11 至 P-14 的专用 GUI 测试均已通过：

1. 临时 INI 能恢复中文路径、列表显示名、最后 URL 和历史顺序；启动恢复不会调用
   播放内核、直播清单服务或歌词服务。
2. 本地列表的新增、移出、排序和重命名会同步保存；成功直播清单历史按最近使用
   排序、去重并限制为 20 项，失败 URL 不进入成功历史。
3. 历史窗口的回填、删除和取消均符合边界，回填不会发起网络载入；取消载入会忽略
   迟到结果并保留原直播列表。
4. `F11`、`Esc`、`Ctrl+下键`、`Ctrl+上键`、单独 `F5` 和未分配的 `Ctrl+F5`
   行为通过；“帮助 -> 快捷键”窗口内容和“确定”返回通过。
5. “帮助”下同时显示“快捷键”和“直播源”；直播源窗口包含地址、备注两列以及红色
   用途提示，新增、删除、返回、保存按钮使用独立高对比颜色。
6. 点击保存后取消不会写入；窗口内 `Ctrl+S` 确认后会立即持久化。未保存时返回选择
   否会放弃并关闭，点击 `X` 选择是会保存并关闭；所有路径均未调用播放内核或清单
   服务。
7. 主窗口 `Ctrl+M` 能直接打开“直播源”窗口，帮助窗口同步显示该快捷键；打开过程
   不触发播放内核或直播清单服务。

## 3. 人工验收状态

2026-08-07 用户确认当前版本没有问题，以下场景均通过：

1. 历史图标、历史窗口的回填、删除和取消操作正常。
2. “帮助 -> 快捷键”能打开说明窗口，内容清晰，点击“确定”返回主窗口。
3. 连续按 `F11` 能进入和退出全屏，`Ctrl+下键` 静音、`Ctrl+上键` 恢复。
4. 关闭并重启后，本地列表和最后直播清单 URL 恢复，但不会自动播放或载入。
5. “帮助”下存在“快捷键”和“直播源”两个选项；直播源窗口按钮足够醒目，地址与备注
   能保存并在重启后恢复，返回和 `X` 的未保存确认符合预期。
