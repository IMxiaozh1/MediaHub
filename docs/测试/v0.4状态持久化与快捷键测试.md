## 5. 直播源编辑方向键修正

2026-08-10 用户实机发现，直播源资料单元格进入编辑状态后，左方向键可移动光标，
右方向键却没有反应。原因是主窗口为“短按右键定位、长按右键临时倍速”安装了应用级
事件过滤器，但未限制按键必须来自主窗口，导致独立模态窗口的右方向键也被拦截。

新增 P-17 自动化场景先在旧实现上复现失败，再将右键处理范围收紧到主窗口自身。
修正后直播源地址编辑器的右方向键可将光标向右移动，主窗口不会收到定位请求；直播源
保存与关闭流程、主窗口右键短按定位、长按临时倍速和 `Ctrl+左右键` 列表切换等
7 个定向场景通过。Debug 100%、125%、150% 三档完整 GUI CTest `3/3` 通过
（96.11 秒），Debug 全量 CTest `74/74` 通过（125.59 秒），人工验收后的 Release
全量 CTest `74/74` 通过（52.33 秒）。用户在最新 Release 中确认地址和备注编辑器的
左右方向键均可正常移动光标，本次修正人工验收通过。
