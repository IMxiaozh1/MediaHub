# MediaHub v0.7 直播跨页后台播放修复测试

> 日期：2026-08-24。
>
> 状态：Debug/Release 自动化、正式包验证和用户真实直播人工验收通过。

## 1. 问题

用户反馈直播页正在播放时切换到网页页，直播会停止；切回直播页刷新当前直播间后，
可能显示“无法连接网络媒体”，关闭后重新打开仍不能恢复。用户要求直播在本地、直播、
网页三个页面之间切换时保持后台播放，只有明确点击暂停、停止、切台或关闭程序才改变
播放会话。

根因是 `PlayerPresenter::changeDisplayMode()` 把进入网页页当作播放控制操作：当原生媒体
处于打开、缓冲或播放状态时会主动调用 `engine.pause()`。直播协议在长时间暂停后可能由
服务端或 libVLC 断开，后续刷新因此进入错误恢复链路。页面切换本应只改变 Qt 页面和
WebView2 的可见性，不应向原生播放内核提交暂停命令。

## 2. 修复策略

1. 进入网页页不再调用播放内核的 `pause()`；直播和本地媒体都保持原有播放状态。
2. 切换页面仍只更新 `QStackedWidget`、直播/本地列表和 WebView2 可见性，不销毁视频
   输出窗口、播放器或浏览器 Controller。
3. 保留用户主动暂停、停止、切台、刷新、自动重连和关闭程序的既有语义。
4. 增加“直播播放 -> 网页 -> 直播 -> 手动刷新 -> 重新播放”的连续回归，防止仅验证
   单次切页而遗漏刷新恢复。
