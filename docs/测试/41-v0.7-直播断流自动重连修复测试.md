# MediaHub v0.7 直播断流自动重连修复测试

> 日期：2026-08-24。
>
> 状态：Debug/Release 自动化回归、Release 包验证和用户 Debug 实机确认通过。

## 1. 问题

用户反馈直播播放一段时间后，libVLC 偶尔显示“播放已结束”，但直播实际没有结束；
再次双击可以恢复，卡住后切换其他直播源有时也无法打开，只能重启程序。用户还要求
自动/手动刷新后保持原音量和静音状态。

## 2. 修复策略

1. 网络直播只要曾经进入 `Playing`，收到 libVLC 的 `Failed` 或 `EndReached` 就进入
   自动恢复，不把这类短暂断流当作本地媒体自然结束。
2. 自动重连按 `1、2、4` 秒退避，单次播放会话最多 3 次；重连成功后重新计数。
3. 首次连接从未进入 `Playing` 的坏源不自动重试，仍显示连接失败，避免反复请求无效源。
4. 手动停止、手动刷新、双击当前或其他直播源、切换本地媒体和关闭程序都会取消旧的
   重连计时器。
5. 进入 `Playing` 时重新应用 Presenter 保存的音量和静音状态；重连及手动刷新不改动
   音量滑块或静音标志。
6. 内核控制线程不再周期性调用可能阻塞的 libVLC 网络统计接口；只在有明确控制命令时
   从等待中唤醒，避免卡住直播阻塞刷新、切台和停止。
