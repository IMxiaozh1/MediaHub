# 浏览器日常增强增量 01 测试

> 范围：阶段一“后台连续播放与声音控制”。网页模块继续与本地媒体、直播播放链路隔离。
>
> 状态：阶段一实现已集成；后续真实 Runtime `57/57`、完整构建矩阵和规划 12/13
> 人工门禁均已通过。正文保留阶段实施时的环境失败和原始人工矩阵。

## 1. 验证目标

1. 从网页切到本地、直播或其他网页标签时只改变 Controller 可见性，不主动静音、挂起、
   重建或重新导航网页。
2. 全局网页静音与每标签用户静音相互独立；解除全局静音恢复各标签原有选择。
3. WebView2 每个标签分别上报音频活动，标签 ID、代次和关闭后的迟到事件边界保持稳定。
4. 主窗口在本地、直播和网页模式都能显示可听网页标签数量，不借此跨模块控制播放器。
5. 后台敏感请求继续安全拒绝或取消；正在播放、存在媒体活动或活动下载的标签不得睡眠。

## 3. 已通过的自动化

以下定向用例已通过：

- `deactivatesAndActivatesBrowserInSafeOrder`：离开和返回网页模式只发送可见性命令，
  不发送静音或挂起命令。
- `tracksIndependentTabAudioAndMuteState`：两个标签分别维护音频活动和用户静音，标签
  切换不覆盖原选择，可听数量按有效静音计算。
- `showsAudibleWebTabCountAcrossDisplayModes`：本地、直播和网页模式之间切换时声音标签
  数量保持显示，不产生播放器命令。
- `registersAudioStateForEveryTabAndKeepsMuteIndependent`：主标签和次级标签均注册、读取、
  撤销 WebView2 音频状态事件；激活标签不再改变静音，生效静音不再依赖当前标签身份。

后续阶段集成完成后，本阶段行为已纳入最新回归：

```text
ctest --test-dir cmake-build-debug -I 1,90 --output-on-failure
```

结果为 Debug CTest `90/90` 通过，总用时 188.26 秒；依赖真实 Controller 的第 91 项
`integration.webview2.initialization` 不包含在该 90 项组合中，并已按下一节单独尝试。
其中浏览器相关 12 项 CTest `12/12` 通过，BrowserPage 程序内部 `65/65` 通过，
WebView2 非 Runtime 契约 `41/41` 通过。下载中心集成曾引入的全屏回归已修复并纳入
上述结果；新增 `suspensionDefaultsToActiveForBackgroundPlayback` 确认 Controller Ready
后不会误触发挂起或强制静音，下载拒绝路径/事务启动失败均由 `onDownloadUpdated` 报告
`Failed` 终态。

## 4. 实施期间环境限制

当前环境已尝试完整 WebView2 初始化回归，但未取得可用 Controller，必须按实际失败记录：

```text
ctest --test-dir cmake-build-debug -R webview2 --output-on-failure
```

- Runtime 定向程序实际为 `42 passed, 10 failed`。十项失败均发生在 Controller 未进入
  Ready；最终固定失败为 `invalid_initialization_input`，HRESULT `-2147024809`。
- `stage1_webview2_probe` 在排除 Runtime 的回归中通过；Probe 只验证 Runtime 可被发现，
  不替代 WebView2 Controller 初始化和媒体回归。
- 该结果只证明当前环境/Runtime 无法完成初始化，不得写成 Runtime 通过；原 v0.6 的
  Runtime 通过证据也不能替代本次修改后的回归。

普通 Windows 环境至少需要补跑：

```text
ctest --test-dir cmake-build-debug -R integration.webview2.initialization --output-on-failure
```

普通环境回归必须使用本轮完整 Debug 构建生成的 `MediaHubWebView2Probe.exe` 和测试程序，
不得以旧构建产物替代本次结果。

未 Ready 失败；真实网页后台媒体、声音输出、安全请求体验和退出进程观察仍未完成。

待补”。

## 9. 最终归档结论

阶段一生产实现已进入 v0.6 最终版本。网页切离只改变可见性，不主动挂起、静音、销毁或
重新导航 Controller；后台播放、每标签静音、下载和关闭语义均有自动化证据。规划 12/13
完成后的 Debug/Release 全量 CTest 均为 `91/91`，用户已通过持续拖动、浅色界面和主要
侧栏交互门禁。原 BDA-M01 至 BDA-M08 未逐项补证的真实网站组合继续作为兼容性清单。
