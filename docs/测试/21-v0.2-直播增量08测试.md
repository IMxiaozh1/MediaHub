## 2. 功能与人工证据

第六与第七增量测试已经逐项记录以下人工结果，本增量不把自动化冒充真实音画覆盖：

- 用户清单按真实名称和来源顺序显示，双击条目可播放直播音画。
- 停止、`F5`/按钮刷新和无效清单失败保留正常。
- 本地 MP3/MP4 与直播列表互不混入，切换标签不停止当前媒体。
- 卡顿源连续切换后，画面只保留在 MediaHub 视频区域，不再出现独立 libVLC 窗口。
- 直播右键播放/暂停、停止、标记、收藏、滚动保持和定位正在播放全部通过。
- 替换 `icons/taskbar.png`、`icons/window.jpg` 并连续重启后，任务栏与标题栏图标分别
  按对应图片更新。

远程清单成功、失败、超时、过大、条目过多、不安全重定向、非法 UTF-8、普通 HLS、
相对地址、重复、取消和迟到结果隔离由自动化覆盖。

## 4. 隔离运行

使用 `tools/stage12_isolated_smoke.ps1` 清空 Qt/VLC 插件环境变量，将 `PATH` 缩减到
Windows 系统目录，并从发布目录打开仓库外的真实 `test.mp3`：

1. `MediaHub.exe` 启动后持续响应，没有提前退出。
2. Qt5Core、Qt5Gui、Qt5Network、Qt5Widgets、libvlc 和 libvlccore 均从发布目录加载。
3. 请求正常关闭后在 10 秒上限内退出，退出码为 `0`。

本次隔离进程 PID 为 `7564`。媒体文件仅用于本机验收，没有复制到发布目录或仓库。

## 6. 交付结论与限制

v0.2 第八增量满足规划通过条件，本地自用交付通过。公开分发仍保留以下限制：

1. 未在第二台无开发环境 Windows 或虚拟机复测。
2. 未在 Windows 系统显示设置 125%/150% 下重新做人眼回归。
3. MediaHub 自身源码许可证未决定，完整 VLC 插件目录的许可仍需逐项复核。
4. 真实直播可用性、音画质量和同步依赖用户提供的合法来源，自动化无法替代感官验收。

这些限制不阻塞当前本机自用交付，但在解决前不得表述为已正式公开发布。
