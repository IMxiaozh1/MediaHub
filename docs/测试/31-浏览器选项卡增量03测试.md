## Runtime 通过证据

新增 `clearsSharedProfileFromSecondaryTab`：主标签在受控 loopback 页面写入持久 Cookie、
LocalStorage 和 IndexedDB，直接创建共享 Profile 的次级标签读取三类资料，再从次级标签
执行完整清除并确认三类资料都变为空。该用例不依赖 `window.open` 才能创建标签。

2026-08-12 用户在普通 Windows PowerShell 使用最终 Debug 构建运行：

```text
.\cmake-build-debug\tests\mediahub_webview2_tests.exe
```

完整程序得到 `46 passed, 0 failed, 0 skipped`，耗时 12.675 秒；以下关键用例全部通过：

- `persistsAndClearsOnlyTemporaryProfileData`
- `clearsSharedProfileFromSecondaryTab`
- `createsSharedProfileTabAndClosesIt`
- `popupSharesTheTemporaryProfile`

因此共享 Profile、次级标签清除和 `window.open` 转标签的 Runtime 门禁满足。Codex 沙箱
Renderer 超时与普通权限自动审批服务故障只保留为环境历史，不覆盖本次普通环境结果。
