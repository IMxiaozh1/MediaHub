# MediaHub 在线歌词增量测试

> 状态：实现、自动化、两首真实 MP3 与全屏响应式显示验收通过（2026-08-04）。
>
> 范围：纯音频歌词按钮、ID3 标签、内嵌歌词、在线查询、缓存、同步显示、单曲校准、
> 响应式字号和安全降级。

## 1. 需求与交互

- 音量按钮右侧增加 36×36 圆形按钮，按钮文字固定为“词”。
- 没有媒体或播放视频时按钮禁用；纯音频打开后按钮可用。
- 第一次点击切换到歌词页并异步查询，再次点击返回原音频波形页。
- 同一首歌曲重复切换歌词页不重复请求；切歌会取消旧请求并清除旧歌词。
- 同步歌词显示当前行和前后文，当前行使用强调色；播放进度越过时间戳后更新。
- 只有普通歌词时显示可滚动全文；无结果、超时和网络错误均显示内联提示。
- 歌词页保持既有全屏、播放控制、倍速和主进度条行为，不增加第二条进度条。
- 同步歌词支持按单曲以 0.5 秒步进提前、延后和重置；校准值下次播放继续生效。
- 同步歌词、普通歌词、左上角文件名、来源标签和校准控件根据实际歌词区域宽高自动
  缩放；按钮文字、高度和点击区域同步变化，退出全屏后自动恢复紧凑尺寸。

## 2. 数据源与匹配

查询顺序如下：

1. MP3 ID3v2/ID3v1 标题、艺术家和专辑标签，以及 ID3 `USLT` 内嵌歌词。
2. 酷狗歌曲搜索、歌曲分组、音频条目哈希匹配和同步歌词。
3. 网易云音乐歌曲搜索与时间轴歌词；存在翻译歌词时按相同时间戳合并。
4. LRCLIB 的 `syncedLyrics` 或 `plainLyrics`。
5. TheAudioDB 的 `strTrackLyrics` 普通歌词。

在线匹配综合标题、艺术家、专辑和歌曲时长。标题必须相同或高度接近；艺术家不匹配
通常会显著降权。对于“歌曲名（电视剧插曲）”一类标签，查询和匹配会移除标题尾部
说明；只有核心标题完全一致且时长相差不超过 5 秒时，才允许曲库与本地使用不同的
演唱者署名。时长相差超过 15 秒仍会降权，避免误取其他同名歌曲。
候选显示标题中的 DJ、Live、Remix、Cover、纯音乐、伴奏和 TV 版等录音变体必须与
本地标题一致，否则直接排除；不能只看曲库提供的“原始标题”。

当前 Qt 5.14.2 网络模块使用动态 OpenSSL 1.1，但本机未安装对应运行库。实现会检测
`QSslSocket::supportsSsl()`：可用时网易云、LRCLIB 和 TheAudioDB 使用 HTTPS；不可用
时酷狗和网易云使用当前仍可访问的 HTTP 接口，LRCLIB 和 TheAudioDB 不发起无法成功
的请求，并显示备用源暂时不可用。后续可升级 Qt/网络实现或按许可证引入受支持的
TLS 运行库。

## 3. 线程、缓存与隐私

- `QNetworkAccessManager` 在 GUI 线程异步工作，不阻塞播放、波形或 libVLC 线程。
- 每个请求最多等待 6 秒；切歌和关闭会取消进行中的网络回复。
- 缓存键由规范化后的标题、艺术家、专辑和时长计算 SHA-256，不包含媒体完整路径。
- 缓存写入 Qt `CacheLocation/lyrics`，不进入仓库，不修改用户媒体文件。
- 单曲校准使用媒体显示名、匹配标题和艺术家的 SHA-256 键写入用户 INI 配置；只保存
  毫秒偏移，不保存完整媒体路径。重置会删除对应设置。
- 在线请求只发送歌曲标签和时长，不上传媒体内容，也不发送本地文件路径。
- 酷狗和网易云接口属于非官方内部接口，只适合当前个人本地使用；正式发布前需重新
  评估稳定性、平台条款和歌词版权。
- TheAudioDB 免费接口限每分钟 30 次；免费条款不允许直接发布到应用商店，正式分发
  前需要取得适合的订阅和数据使用授权。

## 4. 自动化结果

新增 Qt Test 覆盖：

- 初始状态下“词”按钮文字、尺寸、圆形样式和禁用状态。
- “词”按钮位于音量右侧，并与全部播放控件保持同一行。
- 纯音频点击后只请求一次，歌词页与波形页可以往返切换。
- 查询参数保留媒体源路径用于本地 ID3 读取，同时传入已知歌曲时长。
- 同步歌词在 12 秒和 21 秒位置分别高亮对应行。
- LRC 支持一行多个时间戳以及 1、2、3 位小数，普通歌词会移除时间戳和元数据标签。
- 覆盖标题尾缀和演唱者署名不同但时长吻合的候选，同时拒绝时长明显不同的同名歌。
- 覆盖酷狗搜索结果的嵌套歌曲分组、Base64 LRC 解码，以及“原始标题相同但显示标题
  为纯音乐”的错误录音版本排除。
- 覆盖歌词延后 0.5 秒后的当前行切换、同曲重新载入保留设置，以及重置恢复原时间轴。
- 覆盖 `1600×1040` 歌词区域的响应式字号：当前行 `91px`、上下文 `56px`、普通歌词
  `42px`、文件名 `33px`、来源标签 `24px`、校准控件 `27px` 和按钮高度 `51px`。
- 自动化使用假歌词服务，不访问互联网，不依赖第三方服务可用性。

2026-08-04 实际结果：

- Debug 歌词相关 GUI 套件通过。
- Release 全量 CTest `44/44` 通过，最终复测约 13.97 秒。
- Release 部署结果包含 `Qt5Network.dll` 和 bearer 插件。
- “套马杆”使用酷狗 `39` 行同步歌词，用户确认原始时间轴同步正确，证明播放器位置
  推进不存在统一偏移。
- “够爱”先因错误候选降级为网易云 `39` 行歌词；排除 DJ/纯音乐录音变体后取得酷狗
  `71` 行同步歌词。酷狗提供的多份 LRC 正文时间戳基本相同，仍稍快，使用该单曲
  `+0.5 秒` 校准后达到可用状态，不影响“套马杆”。未输出或提交歌词正文。
