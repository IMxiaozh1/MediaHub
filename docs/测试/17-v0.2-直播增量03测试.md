## 1. 历史自动重连验收项（已被最终策略取代）

- [x] 已经进入 `Playing` 的网络媒体发生 `Failed` 或 `EndReached` 后触发自动重连。
- [x] libVLC 保持 `Playing` 但输入、解复用、解码、输出统计和已观察到的网络播放
  位置连续 15 秒没有活动时，即使没有 `Failed` 或 `EndReached` 也触发自动重连。
- [x] 活动统计每 250ms 在内核侧采样，Presenter 每 500ms 读取；网络播放位置前进可
  作为统计冻结时的活动兜底。从未提供统计和位置活动时不推断断流。
- [x] 普通 `Buffering` 只更新缓冲百分比，不启动重连计时器，也不重复打开媒体。
- [x] 每次用户主动播放会话最多自动重连 3 次，退避依次为 1、2、4 秒。
- [x] 重连尝试仍受 15 秒打开超时限制；一次重连超时后进入下一次退避，不无限等待。
- [x] 三次均失败后显示“自动重连失败”和中文提示，播放按钮允许用户手动重试。
- [x] 用户手动重试会重置重连预算，下一次断流重新从 `1/3` 开始。
- [x] 等待重连或正在重连时点击停止，会立即取消计时器和旧媒体事件。
- [x] 切换本地媒体、切换其他列表项、移除当前项或关闭程序后，不再重连旧地址。
- [x] 会话内最近地址最多保留 10 条，自动去重并按最近使用顺序排列。
- [x] 非法地址不进入历史；新建窗口会话为空，不通过 `QSettings` 或文件持久化。
- [x] 完整 URL、用户信息、查询参数和片段不进入日志或播放列表显示名。

- [x] 保持测试流不可用，确认只尝试 3 次，之后停止重连且窗口始终响应。

## 3. 最终手动刷新验收项

- [x] 当前媒体是网络直播时显示“刷新直播”按钮；本地歌曲和视频不显示。
- [x] 正在播放、缓冲、连接失败或普通画面停顿时，点击按钮都重新打开当前网络项。
- [x] `F5` 与按钮走同一刷新入口；本地媒体按 `F5` 不执行打开、播放或定位命令。
- [x] 刷新不新增播放列表项目，不重复会话内最近地址，不泄漏完整 URL。
- [x] 网络媒体明确 `Failed` 或 `EndReached` 后不自动打开，显示
  “直播已断开，请点击刷新”。
- [x] 刷新继续使用独立 libVLC 实例，保留音量和静音状态，旧直播迟到事件不覆盖
  新播放器。
- [x] Release 播放真实直播时点击刷新按钮，画面和声音能够重新开始。
- [x] Release 播放真实直播时按 `F5`，画面和声音能够再次重新开始。
- [x] 多次刷新后列表项和最近地址不重复；切回本地歌曲后立即有声音。

## 4. 实机验收记录

测试源为本机可控 HTTP MPEG-TS，中继地址为 `127.0.0.1:18767/live.ts`。该地址只用于
本机验收，未写入源码、测试数据或日志。

首次停止中继时发现 libVLC 可以在已经没有输入数据后长期保持 `Playing`，且不发送
`Failed` 或 `EndReached`。因此只监听终止事件不能满足真实断流恢复。增加活动统计
看门狗后，实机观察到以下状态序列：

```text
正在播放
-> 直播已断开，1 秒后重连（1/3）
-> 正在重连（1/3）...
-> 正在播放
```

用户确认自动恢复后画面和声音正常。随后保持中继不可用，界面只完成既定的三次尝试，
显示“自动重连失败”，窗口仍响应且播放按钮可用；恢复中继后点击播放可手动恢复，证明
新的用户播放会话会重置次数。正常直播播放时点击停止，再停止和恢复中继并等待 8 秒，
界面保持“已停止”，没有迟到重连。

会话内重新打开网络地址对话框时，可编辑下拉框包含刚使用的地址；关闭并重启程序后，
输入框和下拉列表为空。最后先把本地《套马杆》加入播放列表，再播放直播；停止中继后
切换到歌曲并恢复中继，超过 10 秒仍持续播放本地歌曲，旧直播没有抢回画面或声音。

封存后的公网流兼容性复验发现，HTTP-FLV 在画面和声音持续正常时，libVLC 活动统计
会出现约 5 至 13 秒的短暂冻结，原 6 秒确认窗口会误触发一次重连。即使把确认窗口
延长到 15 秒并用播放位置兜底，也无法保证所有协议和源站都能可靠判断。用户最终决定
取消自动判断，通过按钮或 `F5` 在观察到卡顿时主动刷新。另一次复验发现直播切回本地
歌曲后进度继续前进但暂时无声，调节一次音量才恢复；根因是旧、
新播放器共享 libVLC 实例，旧直播的异步停止会影响新播放器音频状态。跨媒体切换改用
独立实例，并在新播放器进入 `Playing` 后重设音量与静音状态。用户按直播 A、直播 B、
本地歌曲的顺序复验，三步音画均正常，歌曲无需调节音量即可立即听到声音。公网地址
仅用于人工输入，没有写入源码、测试数据或本文档。

2026-08-06 启动最新 Release 后，用户先后确认点击“刷新直播”和按 `F5` 均能重新
恢复当前真实直播的画面与声音；随后直接切换到本地歌曲，歌曲立即有声音，不需要
调节音量。刷新不重复列表项或最近地址的边界同时由 GUI 自动化覆盖。

## 6. 当前结论

历史有限自动重连的代码和实机证据已保留，但不再代表当前产品行为。最终版本不会
自动判断普通卡顿或重连；用户可以随时通过按钮或 `F5` 刷新当前直播，最近地址仍只
存在当前进程，跨媒体切换不会丢失声音或被旧直播覆盖。自动化、Release 按钮、
`F5` 和刷新后本地声音实机验收均已通过，本增量封存。
