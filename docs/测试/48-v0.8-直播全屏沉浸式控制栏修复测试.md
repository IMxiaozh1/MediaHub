# MediaHub v0.8 直播全屏沉浸式控制栏修复测试

> 日期：2026-09-04。
>
> 状态：已完成实现、Debug/Release 回归、用户人工验收和正式交付。

## 1. 问题与目标

直播页面进入真正的全屏后，底部播放控制栏会遮挡画面。修复后，直播全屏隐藏整个底部
控制栏，保留 F11/Esc 全屏切换和上下方向键音量快捷键；退出全屏恢复控制栏。Windows
标题栏最大化和小窗口播放继续显示原有控制栏。

## 2. 实现

`MainWindow` 增加直播全屏沉浸状态，仅在 `DisplayMode::Live` 通过全屏按钮或 F11 进入
全屏时启用。沉浸状态只隐藏 `transportPanel`，不禁用或移除原有快捷键；窗口状态变化和
显示模式切换会同步恢复可见性。普通最大化和 `isMiniPlayer_` 均不进入沉浸状态。

## 3. 自动化回归

新增 `hidesLiveTransportOnlyInFullScreen`，覆盖以下场景：

1. 直播全屏隐藏底部控制栏，按下方向键仍提交音量调整。
2. F11 退出全屏后恢复控制栏。
3. 普通最大化继续显示控制栏，小窗口播放既有回归保持通过。
