# MediaHub v0.8 直播搜索清空滚动定位修复测试

> 日期：2026-09-03。
>
> 状态：已完成实现、定向回归和 Release 全量回归。

## 1. 问题与目标

用户反馈直播列表在搜索后清空搜索条件会回到第一行。修复后，搜索期间播放某个频道再
清空搜索时，列表自动定位到该频道；搜索期间没有播放频道时，列表恢复到开始搜索前的
滚动位置。

## 2. 根因与实现

直播过滤通过隐藏原始模型行实现。Qt 在隐藏行集合变化时会重新计算滚动范围，清空搜索
时可能把滚动值压回 `0`。`MainWindow` 现在在搜索开始时按“全部直播 / 我的收藏”分别
保存滚动位置，并在搜索期间记录由双击或播放菜单触发的原始行。清空搜索后，若记录到
播放行则居中定位该行，否则恢复搜索前的位置；延迟布局任务会检查当前搜索状态和范围，
不会覆盖后续操作。

## 3. 自动化回归

新增 `restoresOrLocatesAfterClearingLivePlaylistSearch`，使用 80 个直播源覆盖以下场景：

1. 在非首行位置开始搜索，未播放频道，清空后恢复原滚动值。
2. 在另一非首行位置开始搜索，双击第 70 行播放，清空后第 70 行位于可见区域且保持当前选中。
