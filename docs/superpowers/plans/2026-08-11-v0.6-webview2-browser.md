# MediaHub v0.6 WebView2 Browser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变现有 libVLC 播放链路和模块边界的前提下，为 Windows x64 MediaHub 增加可持久登录、可安全授权并支持网页视频的 WebView2 第三展示模式。

**Architecture:** `mediahub_gui_support` 持有不暴露 COM/WebView2 类型的浏览器抽象、页面控件和模式协调；`mediahub_browser_webview2` 独立链接固定的 Microsoft WebView2 SDK，并由 `apps/gui/main.cpp` 组合根注入。GUI 测试使用 `FakeBrowserBackend`，真实集成测试只访问 `127.0.0.1` 并使用临时 Profile，Core-only 配置完全不查找 WebView2。

**Tech Stack:** C++20、Qt 5.14.2 Widgets/Test/Network、CMake 3.20+、Microsoft WebView2 SDK 1.0.4129.50、Windows COM/WRL、GoogleTest/Qt Test。

---

- [x] **Step 4: 实现无副作用地址分类**

```cpp
BrowserAddress normalizeBrowserAddress(const QString& input) {
    const QString trimmed = input.trimmed();
    if (trimmed.isEmpty()) {
        return {BrowserAddressKind::Invalid, {}};
    }
    const QString candidate = trimmed.contains(QStringLiteral(":"))
                                  ? trimmed
                                  : QStringLiteral("https://") + trimmed;
    const QUrl url(candidate, QUrl::StrictMode);
    const QString scheme = url.scheme().toLower();
    if ((scheme == QStringLiteral("http") || scheme == QStringLiteral("https")) &&
        !url.host().isEmpty() && url.port(-1) >= -1) {
        return {BrowserAddressKind::Web, url.toString(QUrl::FullyEncoded)};
    }
    if (scheme == QStringLiteral("file")) {
        return {BrowserAddressKind::LocalFile, url.toString(QUrl::FullyEncoded)};
    }
    if (scheme == QStringLiteral("javascript") || scheme == QStringLiteral("data") ||
        scheme == QStringLiteral("edge") || scheme == QStringLiteral("devtools")) {
        return {BrowserAddressKind::Blocked, {}};
    }
    return url.isValid() && !scheme.isEmpty()
               ? BrowserAddress{BrowserAddressKind::ExternalProtocol,
                                url.toString(QUrl::FullyEncoded)}
               : BrowserAddress{BrowserAddressKind::Invalid, {}};
}
```
