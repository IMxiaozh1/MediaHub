## 当前已确定

- 项目使用 C++20 和 Qt 5.14.2 Widgets。
- 播放内核采用 libVLC，藏在 `PlayerEngine` 纯虚接口之后。
- 播放输入仍只接受本地音视频；网络能力只用于按标签查询歌词与音频元数据。
- v0.2 增加 URL 直播，v0.3 增加自研 FFmpeg 内核并与 libVLC 内核并存。
- 核心层不依赖 Qt 和 libVLC；GUI 层不链接 libVLC。
- `main.cpp` 是全项目唯一知道具体内核存在的地方。
- 内核事件回调发生在 libVLC 线程，必须经统一的桥接层投递到 GUI 主线程。
- 内核事件回调中禁止操作控件，禁止调用会等待内核线程的接口。
- 播放内核的释放顺序固定为六步，第一步必须是解除事件监听。
- 位置事件节流在内核实现层完成，不在界面层。
- libVLC 不进入 Git 仓库，通过 `MEDIAHUB_VLC_ROOT` 指向本机 SDK 目录。
- 测试使用假内核与哑音视频输出，不依赖真实声卡和显示设备。
- 音画输出效果依赖人工验收，没有自动化覆盖，交付文档必须如实声明。
- 不在仓库中提交任何有版权的音视频素材。
- 采用小步结对开发：每次只实现一个可审查增量。

## 协作约定

1. 每个增量开始前先说明目标、文件范围和验收方式。
2. 单次尽量只改 1～3 个文件。
3. 改动完成后先展示 diff、构建结果和设计理由。
4. 阶段测试和文档通过后自动提交；远程无冲突且认证可用时自动推送并继续下一阶段。
5. 推送失败时保留本地提交并记录原因，禁止强制覆盖远端，不扩展计划外功能。
